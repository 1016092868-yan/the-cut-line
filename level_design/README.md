## 四、Boss递进链

```
4月「清算」→ 系统对你做了一件事（你无法控制）
7月「临界」→ 系统找到你的弱点（你在应对）
9月「锁定」→ 你选择了你的命运（你在承受）

无力 → 恐惧 → 决绝
```
