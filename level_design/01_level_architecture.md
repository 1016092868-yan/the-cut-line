# 《斩杀线》关卡架构设计 v1.0

> LevelDesigner | 基于 NarrativeDesigner v3.2 + GameDesigner v1.1
> 游戏类型：生存策略 × 时间管理 × 叙事事件
> 关卡定义：12个月 = 12个关卡，每月是独立的策略考题

---

## 一、关卡设计理念

### 1.1 什么是"关卡"？

在《斩杀线》中，**一个月就是一个关卡**。每个关卡的核心不是"到达终点"，而是**"在这个月的约束下活下来，且净资产不跌过斩杀线"**。

### 1.2 关卡设计原则

1. **每月是独特的策略考题** — 不是数值递增，而是不同的约束条件、事件组合、道德困境
2. **教学在关卡中发生** — 前5个月逐步解锁系统，后续月份考验综合运用
3. **高潮月有Boss机制** — 4月/7月/9月有独特的不可回避的Boss级事件
4. **不同角色=不同难度模式** — 同一月份，不同角色面对不同约束（而非不同数值）
5. **关卡在第二周目变形** — 同一角色第二次玩时，部分约束和事件变化

### 1.3 关卡五要素

每个关卡（月）由五个要素定义：

```
关卡 = 胜利条件 + 约束条件 + 事件池 + 叙事锚点 + 难度参数

胜利条件：净资产 ≥ 斩杀线阈值（至少$0）
约束条件：本月的时间块上限、账单金额、系统解锁状态
事件池：本月可触发的固定事件 + 随机事件
叙事锚点：本月的叙事主题、角色独白风格
难度参数：负面事件概率、意外支出概率、斩杀线波动
```

## 二、关卡类型体系

### 2.1 五种关卡类型

| 类型 | 占比 | 核心挑战 | 示例月份 |
|------|:---:|----------|:--------:|
| 🟢 **教学关** | 3/12 | 引入新系统，低压力 | 10月、11月、1月 |
| 🟡 **标准关** | 4/12 | 正常压力，自由策略 | 12月、2月、3月、5月 |
| 🟠 **压力关** | 2/12 | 高压力，多线约束 | 6月、8月 |
| 🔴 **Boss关** | 3/12 | 不可回避的Boss事件，极高压力 | 4月、7月、9月 |
| ⚪ **结算关** | 1/12 | 结局呈现，无新事件 | 10月 |

### 2.2 各类型详细规格

#### 🟢 教学关

```
特征：
  - 系统未完全解锁（逐月解锁）
  - 负面事件概率：-30%
  - 意外支出概率：-50%
  - 斩杀线仅体力维度激活（宽松阈值）
  - 1个固定引导事件 + 1个随机事件

设计意图：
  让玩家在低压力下学习系统操作。
  不是"简单"——是"安全的学习空间"。

教学关之间：
  10月（工作+休息）→ 11月（+加班）→ 1月（+学习）
  每个教学关只引入1个新时间块。
```

#### 🟡 标准关

```
特征：
  - 全部系统已解锁（或接近全解锁）
  - 负面事件概率：基准
  - 意外支出概率：基准
  - 斩杀线按当前状态正常运作
  - 2-3个随机事件

设计意图：
  玩家在正常压力下实践策略。
  每个月有独特的季节事件锚点。
```

#### 🟠 压力关

```
特征：
  - 负面事件概率：+20%
  - 意外支出概率：+30%
  - 斩杀线阈值收紧10%
  - 至少1个高压事件（E-H系列）
  - 时间块可能被外部因素限制（如：本月强制加班20h）

设计意图：
  考验玩家在高压下的资源管理能力。
  是Boss关的前奏——让玩家为更难的挑战做准备。
```

#### 🔴 Boss关

```
特征：
  - 不可回避的Boss事件（强制触发）
  - 负面事件概率：+50%
  - 意外支出概率：+50%
  - 斩杀线阈值收紧20%
  - Boss事件有独特的"失败后果"（不只是数值惩罚——改变叙事路线）

Boss事件设计：
  4月：报税清算——强制财务事件。退税（40%）或补税（60%）。
  7月：斩杀线临界——至少一条斩杀线强制逼近危险级。
  9月：结局路线锁定——最终抉择，路线分叉。

设计意图：
  游戏的高潮节点。玩家的所有前期选择在此汇聚。
  不是"更难的数值"——是"不同的叙事后果"。
```

#### ⚪ 结算关

```
特征：
  - 无新事件
  - 无时间块分配
  - 仅呈现结局叙事和LXP结算
  - 根据前11个月的结果自动判定结局

设计意图：
  收束。让玩家看到12个月旅程的终点。
```
