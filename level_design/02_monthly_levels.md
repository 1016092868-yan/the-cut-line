## 🟢 10月 —「First Month」教学关

```
类型：教学关
叙事主题："你以为准备好了，其实你什么都不知道"
叙事强度：★★☆

胜利条件：净资产 ≥ $0

约束条件：
  已解锁时间块：工作(60h固定)、休息(0-20h)
  未解锁：加班、社交、学习、灰色
  主动行动：不可用
  资产购买：不可用

固定事件：
  E-CHxx-01 角色专属开场事件（强制，揭示角色的"正常"和裂缝）

随机事件池（1个）：
  E-N01 账单总是准时（低概率，教学向——金额减半为$75-$600）
  E-P01 意外之财（低概率，教学向——金额$100-$400）
  E-NU01 旧日回响

难度参数：
  负面事件概率：×0.7
  意外支出概率：×0.5
  账单倍率：×1.0
  斩杀线：仅体力维度激活（宽松阈值：触发=体力<3%）

特殊规则：
  - 首次操作引导：旁白逐步骤引导拖拽滑块
  - 结算时显示"下个月你将解锁加班——用额外时间换取额外收入"

关卡设计意图：
  玩家只有2个滑块。几乎没有策略深度——这是故意的。
  让玩家在最简单的环境中理解"时间=资源"的核心概念。
  结算时让玩家看到：不加班的情况下，月储蓄$330——刚刚够。
```

## 🔴 4月 —「Tax Day」Boss关（第一高潮）

```
类型：Boss关
叙事主题："报税日。可能是退税——可能是补税。你不知道。直到你打开那个信封。"
叙事强度：★★★★★★

胜利条件：净资产 ≥ $0（但补税可能让这个目标变得困难）

约束条件：
  全部系统可用
  Boss事件不可跳过

Boss事件：E-S04 报税日（强制）
  阶段1：报税准备
    → 玩家需要分配2-4h处理税务（从已分配的时间块削减）
    → 如果拒绝处理：自动触发"审计"（最坏结果）

  阶段2：结果揭晓
    → 退税（40%概率）：+$500-$3,000
    → 补税（55%概率）：-$500-$2,000
    → 审计（5%概率）：需要额外8h+可能的大额补税-$3,000-$5,000

  阶段3：后果
    → 退税：喘息——+净资产，+心情
    → 补税：压力——可能触发经济斩杀线警戒
    → 审计：危机——时间+金钱双重消耗

随机事件池（3个）：
  E-H01 催债人的电话（如果经济斩杀线接近）
  E-N04 系统的信
  E-P01 意外之财（低概率）

难度参数：
  负面事件概率：×1.5
  意外支出概率：×1.5
  账单倍率：×1.3（补税叠加）
  斩杀线阈值收紧：-10%

特殊规则：
  - Boss事件不可跳过、不可拒绝
  - 补税金额取决于前6个月的收入——收入越高，补税越多
  - 如果3月的关系裂痕未被处理，4月触发升级版

关卡设计意图：
  第一高潮。财务清算——前6个月的所有选择在此汇聚。
  玩家无法控制报税结果——只能承受后果。
  这是"系统"最直接的体现——无论你如何选择，税单总会来。
```

## 🟠 8月 —「Final Choice」压力关

```
类型：压力关
叙事主题："你必须选择。合规？灰色？还是放弃？"
叙事强度：★★★★★★

胜利条件：净资产 ≥ $0

约束条件：
  全部系统可用
  路线分叉——本月选择影响结局

固定事件：
  最终抉择事件（强制——三选一）：
    → 合规路线：继续合法策略，寻求稳定（结局A方向）
    → 灰色路线：深度卷入灰色经济，高风险高回报（结局B方向）
    → 放弃：减少努力，接受命运（结局C方向）

  路线效果：
    → 合规：下月额外解锁"社区信用合作社"选项，贷款利率-2%
    → 灰色：下月灰色上限+10h，但法律风险概率翻倍
    → 放弃：下月时间块全部自动分配，玩家不再有选择权

随机事件池（3个）：
  E-H01 催债人的电话
  E-G02 同事的过错
  E-P07 社区的回报
  E-N07 意外的访客

难度参数：
  负面事件概率：×1.2
  意外支出概率：×1.2
  账单倍率：×1.1

特殊规则：
  - 路线分叉不可逆——本月选择锁定9月的事件池和结局方向
  - 如果7月选择了"去老铁厂遗址"——观测者路线在8月继续推进
  - 结算时显示"你的选择将决定最后两个月。"

关卡设计意图：
  路线分叉——玩家的价值观在此转化为具体的选择。
  不是"好vs坏"——是三种不同的代价。
```

## 🔴 9月 —「Lock-in」Boss关（第三高潮）

```
类型：Boss关
叙事主题："结局锁定了。最后几步——无法回头。"
叙事强度：★★★★★★★

胜利条件：净资产 ≥ $0（但结局路线已定，此关影响结局等级）

约束条件：
  全部系统可用
  结局路线已锁定（8月选择决定）
  Boss事件不可跳过

Boss事件：结局路线锁定（强制）
  合规路线Boss：
    → 最后的考验：一次意外的大额支出（$2,000-$5,000）
    → 玩家需要在不借助灰色手段的情况下度过
    → 成功：结局A达成条件+1
    → 失败：跌至结局C边缘

  灰色路线Boss：
    → 利奥的"最后的人情"——一个高风险高回报的机会
    → 成功（40%）：+$10,000-$30,000
    → 失败（60%）：灰色网络崩溃，收入归零，可能触发法律后果

  放弃路线Boss：
    → 没有Boss——玩家只是看着事情发生
    → 但可能出现"意外的转机"（10%概率——观测者或社区的最后一搏）

  隐藏路线Boss（仅观测者路线）：
    → 帮助至少2个NPC度过他们的斩杀线危机
    → 每个NPC需要时间+金钱+特定条件
    → 成功帮助≥2个：隐藏结局D解锁

随机事件池（2个）：
  根据路线定制的事件池

难度参数：
  负面事件概率：×1.5
  意外支出概率：×1.5
  账单倍率：×1.3
  斩杀线阈值收紧：-20%

特殊规则：
  - 此关结束后，结局等级（Victim/Survivor/Upper Middle/Elite/Awakened）确定
  - 结算时显示"结束了。不管结果如何。"

关卡设计意图：
  第三高潮——结局锁定。玩家的所有选择在此汇聚。
  不同路线有完全不同的9月体验——增加重玩价值。
  隐藏路线在此达到最终考验——帮助他人而非只顾自己。
```

## ⚪ 10月 —「The End」结算关

```
类型：结算关
叙事主题："结束了。不是胜利的欢呼——是幸存后的沉默。"
叙事强度：★★★★

胜利条件：自动判定

约束条件：
  无时间块分配
  无新事件

流程：
  ① 结局等级判定（基于净资产+资产+斩杀线状态+观测者线）
  ② 结局叙事呈现（根据结局等级和路线）
  ③ 观测者第三封信（仅隐藏结局D路线）
  ④ 12个月回顾（净资产曲线图+关键决策回顾）
  ⑤ LXP结算
  ⑥ 解锁新内容提示
  ⑦ 选择：再来一局 / 换角色 / 主菜单

特殊规则：
  - 净资产年末资产重估值（房产/投资按年增值率重估）
  - 结局呈现使用叙事设计的结局文本（见叙事设计01_world_bible.md）

关卡设计意图：
  收束。让玩家看到12个月旅程的全貌。
  不是"你赢了"或"你输了"——是"你经历了这些"。
  回顾功能让玩家看到自己的决策如何塑造了结局。
```
