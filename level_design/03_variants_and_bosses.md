# 《斩杀线》关卡变体与多周目系统 v1.0

> LevelDesigner | 同一月份×不同角色 = 不同体验 | 同一角色×第二周目 = 不同关卡

---

## 一、不同角色的关卡差异

### 1.1 设计原则

同一月份，不同角色面对的不是"数值不同"——而是**约束不同、事件池不同、叙事锚点不同**。

### 1.2 2月关卡的角色差异示例

2月「Leo's Knock」是利奥首次接触月。不同角色的体验完全不同：

| 角色 | 利奥的台词变体 | 灰色经济的吸引力 | 道德困境核心 |
|------|--------------|:--------------:|------------|
| 马库斯(#1) | "十二个小时。我数了。你不是在生活——是在推迟死亡。" | 极高（月储蓄仅$330） | 为了艾玛——什么代价是可以接受的？ |
| 佐伊(#2) | "Summa Cum Laude。送咖啡。你觉得这是你该做的事？" | 高（学贷压力） | 学历换来的骄傲 vs 生存需要的妥协 |
| 詹姆斯(#4) | "军队教你纪律。这里教你——灵活。" | 低（有稳定政府工作+VA福利） | 退伍军人的道德底线——比大多数人都高 |
| 特伦斯(#18) | "你不需要我。你有信托基金。但你想知道——'真实世界'是什么样的。" | 低（经济无压力） | 好奇 vs 风险——他只是想"体验"，但灰色经济不是体验 |
| 安娜(#7) | "我知道你的——情况。我也有一些朋友——可以帮助处理'文件'。" | 极高（存在斩杀线始终警戒） | 身份安全 vs 非法帮助——两难 |

### 1.3 4月Boss关的角色差异

4月「Tax Day」——报税对不同角色的影响：

| 角色 | 报税复杂度 | 补税风险 | 特殊规则 |
|------|:--------:|:------:|------|
| 马库斯(#1) | 简单（单一收入来源） | 低 | 标准报税体验 |
| 佐伊(#2) | 复杂（三份零工=三份1099） | 高 | 需要额外4h处理税务 |
| 卢娜(#14) | 极复杂（多平台零工=多份1099） | 极高 | 需要额外8h处理税务，审计概率翻倍 |
| 伊桑(#9) | 极复杂（创业亏损抵扣） | 不确定 | 如果创业亏损——可能退税；如果盈利——大额补税 |
| 特伦斯(#18) | 复杂（信托基金+投资收入） | 高 | 补税金额基于被动收入——通常$3,000-$8,000 |

### 1.4 7月Boss关的角色差异

7月「斩杀线临界」——最脆弱维度被强制推至危险：

| 角色 | 最脆弱维度 | Boss事件表现 |
|------|:--------:|------------|
| 马库斯(#1) | 经济 | 净资产强制降至$0——驱逐风险 |
| 佐伊(#2) | 经济 | 学贷公司启动追索——父母房产面临风险 |
| 德里克(#3) | 体力 | 旧伤复发——膝盖需要手术，$2,400 |
| 安娜(#7) | 存在 | ICE传闻——身份验证被触发 |
| 瑞秋(#8) | 体力 | 过劳崩溃——无法工作，需要找人照顾孩子 |
| 特伦斯(#18) | 职业 | 信托基金"断供"——净资产首次跌破$100K |

## 二、多周目关卡变化

### 2.1 设计原则

同一角色第二次玩时，关卡会"变形"——不是更难，而是**不同**。

### 2.2 周目变化表

| 周目 | 变化内容 | 设计意图 |
|:----:|----------|----------|
| **1周目** | 标准体验 | 基线 |
| **2周目** | 部分事件出现"前世记忆"选项（标注💭） | "你好像经历过这个……"——提供额外策略路径 |
| **2周目** | 固定事件的结果随机重掷（如报税：1周目退税→2周目可能补税） | 打破"背板"——同样的策略可能不奏效 |
| **2周目** | 起始现金+$2,000（"教训的价值"） | 轻微优势——但不是碾压 |
| **3周目+** | 解锁"精通模式"——部分约束收紧，但策略选项增加 | 给高手的新挑战 |

### 2.3 "前世记忆"事件示例

2周目时，部分事件出现额外选项：

```
事件：E-N03 关系的裂痕（2周目）

标准选项：
  A. 尽力弥补 → -时间 -资源
  B. 诚实解释 → +可能理解
  C. 找借口 → 短期避免冲突

💭 前世记忆选项（2周目新增）：
  D. "上次我选了找借口。这次——"
     → 效果：直接触发修复（无需消耗额外时间），但角色独白揭示"你记得上次的后果。这次你做了不同的选择。"
     → 代价：前世记忆选项每局仅可使用3次
```

## 三、Boss月设计深度

### 3.1 Boss月的共同特征

| 特征 | 说明 |
|------|------|
| **不可跳过** | Boss事件100%触发，无法拒绝 |
| **多阶段** | Boss事件有2-3个阶段，每阶段有独立的选择 |
| **叙事分叉** | Boss事件的结果不是数值变化——改变叙事路线 |
| **情感峰值** | Boss月是情感曲线的最高/最低点 |
| **全屏演出** | Boss事件使用全屏特效（红色暗角/斩杀时刻动画） |

### 3.2 三个Boss月的设计差异

| 维度 | 4月（报税） | 7月（斩杀线临界） | 9月（结局锁定） |
|------|-----------|-----------------|---------------|
| **触发方式** | 固定月份强制 | 斩杀线状态检查+强制 | 8月选择决定路线 |
| **玩家控制感** | 无——报税结果随机 | 有——可以选择应对策略 | 取决于8月选择 |
| **后果类型** | 财务（钱） | 多维度（最脆弱维度） | 叙事（结局路线） |
| **可逆转性** | 不可逆转（税已报） | 可逆转（危机可恢复） | 不可逆转（路线锁定） |
| **情感目标** | 无力感——"系统不关心你" | 恐惧——"斩杀线就在这里" | 决绝——"这是你的选择" |

## 四、关卡难度模式

### 4.1 三种全局难度

玩家可在游戏开始时选择（类似Hades的God Mode）：

| 难度 | 收入倍率 | 体力上限 | 负面事件 | 账单倍率 | 目标受众 |
|------|:------:|:------:|:------:|:------:|----------|
| 📖 故事模式 | 1.3x | +15 | -10% | 0.8x | 想体验剧情 |
| ⚖ 标准模式 | 1.0x | +0 | +0% | 1.0x | 默认 |
| 💀 硬核模式 | 0.8x | -10 | +10% | 1.2x | 追求挑战 |

### 4.2 暗怜悯机制

连续3次同一月份净资产跌至斩杀线 → 激活：
- 下月负面事件概率 -10%
- 下月意外支出概率 -20%
- 下月结算时出现角色独白："也许这个月会好一点。"

成功后怜悯重置。
