# 《斩杀线》游戏设计文档 GDD v1.1

> GameDesigner | 基于 NarrativeDesigner v3.2 叙事设计
> 游戏类型：生存策略 × 时间管理 × 叙事事件
> 核心玩法：「时间块分配 + 账单风暴」

---

## 一、设计支柱

1. **时间是最稀缺的资源** — 每月120小时，工作吃掉60h，剩下60h是你的全部选择空间
2. **账单不会等你** — 每月固定支出必须支付，逾期有递增后果
3. **事件不预约** — 随机事件在月中出现，要求你重新分配已经排好的时间
4. **你可以主动出击** — 每月1次主动行动（联系旧友/寻找副业/申请贷款/联系利奥/帮助邻居）
5. **斩杀线是活的** — 四重斩杀线全程动态逼近，触发时全屏"斩杀时刻"
6. **资产改变命运** — 仅靠时间块收入无法达到高结局——必须通过购房/投资/创业实现资产增值
7. **角色不是皮肤** — 20个角色各有不同的时间块上限、账单结构和专属事件

## 二、核心玩法循环

### 2.1 月度循环

```
月初账单 → 时间块分配 → 主动行动(可选) → 随机事件(2-3个) → 月末结算 → 斩杀线更新 → 下月
```

每月的5个阶段：

| 阶段 | 玩家操作 | 时长 |
|------|----------|:----:|
| **① 账单到达** | 查看本月账单总额 | ~15秒 |
| **② 时间块分配** | 拖拽6种时间块，分配120小时 | ~60秒 |
| **③ 主动行动** | 可选1次（联系旧友/寻找副业/申请贷款/联系利奥/帮助邻居） | ~20秒 |
| **④ 随机事件** | 2-3个事件弹窗，做出选择 | ~60秒 |
| **⑤ 月末结算** | 查看收入/支出/净资产/斩杀线变化 | ~30秒 |

**单月总时长：约3-4分钟。12个月一局：约45-55分钟。**

### 2.2 年度循环

```
10月(序章) → 11月 → 12月 → 1月 → 2月 → 3月 → 4月(第一高潮) 
→ 5月 → 6月 → 7月(第二高潮) → 8月 → 9月(第三高潮) → 10月(结局)
```

### 2.3 跨局循环

```
角色选择(三选一) → 12个月 → 结局 → LXP结算 → 解锁新内容 → 重新开始
```

### 2.4 新手引导：逐月解锁

| 月份 | 解锁内容 | 引导方式 |
|:----:|----------|----------|
| 10月 | 工作(60h) + 休息(0-20h) | 只有2个滑块，旁白引导 |
| 11月 | + 加班(0-20h) | 闪烁的加班滑块 + 叙事提示 |
| 12月 | + 社交(0-15h) | 强制社交事件 |
| 1月 | + 学习(0-10h) | 叙事提示 |
| 2月 | + 灰色(0-15h) + 主动行动 | 利奥首次接触事件后解锁 |
| 3月+ | 全部系统 | 无引导 |

## 三、核心系统规格

### 3.1 时间块分配系统

| 时间块 | 上限 | 效果 | 风险/代价 |
|--------|:----:|------|-----------|
| 🏢 **工作** | 60h固定 | +基础收入 = 时薪×60h | 无（必须） |
| 🔥 **加班** | 0-20h | +额外收入 = 时薪×1.5×加班小时 | 体力-3/h |
| 🤝 **社交** | 0-15h | +社交值 +可能触发正面事件 | 可能被拒绝 |
| 📚 **学习** | 0-10h | +学历值 +未来收入潜力 | 短期无回报 |
| 😴 **休息** | 0-20h | +体力恢复 = +5体力/h | 收入机会成本 |
| 🕶 **灰色** | 0-15h | +高收入 = $25/h | 法律/安全风险 |

### 3.2 主动行动系统（v1.1新增）

每月1次。消耗时间，从已分配的时间块中扣除：

| 行动 | 消耗 | 成功效果 | 成功概率 |
|------|:----:|----------|:------:|
| 📞 联系旧友 | 2h社交 | 下月触发正面社交事件 | 70% |
| 🔍 寻找副业 | 5h | 下月解锁$200-500/月额外收入 | 50% |
| 🏦 申请贷款 | 2h | 获得贷款选项 | 80% |
| 📝 更新简历 | 3h | 下月触发面试事件 | 60% |
| 🕶 联系利奥 | 1h | 触发灰色经济机会 | 60% |
| 🤝 帮助邻居 | 3h | +社区连接 | 90% |

### 3.3 资产系统（v1.1新增）

仅靠时间块收入无法达到Upper Middle/Elite结局。必须通过资产增值：

| 资产 | 价格(首付) | 月维护 | 年增值 | 触发事件 |
|------|:---------:|:------:|:------:|----------|
| 🏠 南岸公寓 | $40K($5K) | $300 | 3-8% | E-ASSET-01 |
| 🏡 中环联排 | $120K($15K) | $600 | 5-12% | E-ASSET-02 |
| 🏰 北岸房产 | $350K($40K) | $1,500 | 8-20% | E-ASSET-03 |
| 📈 指数基金 | $1K-$20K | $0 | -5%~+15% | E-ASSET-04 |
| 🚀 创业投资 | $5K-$50K | $0 | -100%~+500% | E-ASSET-05 |

### 3.4 婚姻/育儿互动系统（v1.1新增）

婚姻和育儿不只是账单——是月度互动：

**婚姻**：每月结算时额外出现"伴侣互动"（关系值>80%=双人加成；<30%=离婚风险）
**育儿**：每月结算时额外出现"育儿时刻"（亲子关系>80%=情感支撑+5体力；<30%=触发抚养权危机）

### 3.5 四重斩杀线状态机

| 斩杀线 | SAFE | WARNING | DANGER | CRITICAL | TRIGGERED |
|--------|:----:|:-------:|:------:|:--------:|:---------:|
| 经济 | >$5K | $0~$5K | -$5K~$0 | <-$5K | <-$10K且连续3月 |
| 体力 | >70% | 40-70% | 10-40% | 5-10% | <5% |
| 社交 | >60% | 30-60% | 10-30% | 5-10% | <5%且连续2次负面 |
| 存在 | 0项过期 | 1项 | 2项 | 3项 | 全部失效 |

### 3.6 「斩杀时刻」——独特记忆点（v1.1新增）

当任一条斩杀线触发时：全屏变红3秒 + UI冻结 + 大字提示 + 角色独白永久变化。一局仅1-2次，但每次都有重量。

## 四、结局判定（v1.2 修复——对齐叙事设计的4种结局框架）

叙事设计定义了4种结局（逃出生天/灰色永生/跌落/觉醒），玩法设计将其细化为6个等级：

| 结局 | 叙事对应 | 条件 | 目标概率 | 可达性 |
|------|:------:|------|:------:|:------:|
| 💀 Victim | C·跌落 | 净资产<$0 | 20-30% | 高风险策略+意外叠加 |
| 🥉 Survivor | A·逃出生天（基线） | 净资产≥$0 + 灰色总时长<30h | 40-55% | 保守合法策略 |
| 🥈 Upper Middle | A·逃出生天（进阶） | 净资产≥$20K + ≥1资产 + 灰色总时长<30h | 15-25% | 激进合法策略+购房 |
| 🥇 Elite | A·逃出生天（卓越） | 净资产≥$80K + ≥2资产 + 无斩杀线 + 灰色总时长<30h | 3-8% | 合法策略+购房+事件爆发 |
| 🕶 Gray Survivor | B·灰色永生 | 净资产≥$0 + 灰色总时长≥30h | 10-15% | 依赖灰色经济生存 |
| 🔮 Awakened | D·觉醒 | 净资产≥$20K + 观测者线 + 帮助≥2NPC | 2-5% | 需要特定事件线 |

**结局判定逻辑**：
```
IF 净资产 < $0 → Victim
ELSE IF 观测者线完成 AND 帮助≥2NPC AND 净资产≥$20K → Awakened
ELSE IF 灰色总时长 ≥ 30h AND 净资产 ≥ $0 → Gray Survivor
ELSE IF 净资产 ≥ $80K AND ≥2资产 AND 无斩杀线 → Elite
ELSE IF 净资产 ≥ $20K AND ≥1资产 → Upper Middle
ELSE → Survivor
```

**"灰色永生"的设计意图**：如果玩家在12个月中累计灰色时间≥30h（平均每月2.5h），即使最终净资产为正，也获得"灰色永生"结局而非"逃出生天"。这反映了叙事设计的核心原则——**生存方式定义了你是谁，不只是生存结果。**
