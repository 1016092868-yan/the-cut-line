## 二、核心玩法：一句话

**每个月120小时。工作吃掉60h。账单不会等你。事件不会预约。你可以主动出击。当斩杀线触发时——全屏变红。资产是你跨越阶层的唯一路径。**

---

## 三、月度循环

```
月初账单 → 时间块分配(拖拽滑块) → 主动行动(可选1次) → 随机事件(2-3个) → 月末结算 → 斩杀线更新
```

---

## 四、独特记忆点

**「斩杀时刻」**：当斩杀线触发时——全屏变红3秒、UI冻结、大字提示。一局1-2次。玩家会记住那个瞬间。
