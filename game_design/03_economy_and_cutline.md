## 一、经济系统

### 1.1 核心公式

```
月净现金流 = 月收入 - 月支出

月收入 = 工作收入 + 加班收入 + 灰色收入 + 被动收入 + 事件收入
月支出 = 固定账单 + 意外支出 + 逾期罚款 + 事件支出

净资产 = 上月净资产 + 月净现金流
```

### 1.2 收入来源详解

| 收入来源 | 公式 | 示例（马库斯，时薪$36.67） |
|----------|------|--------------------------|
| 工作收入 | 时薪 × 60h | $2,200 |
| 加班收入 | 时薪 × 1.5 × 加班小时 | +$550（10h加班） |
| 灰色收入 | $25 × 灰色小时 | +$250（10h灰色） |
| 被动收入 | 资产产生 | +$200（如有出租房产） |
| 事件收入 | 事件触发 | +$500（意外之财事件） |

### 1.4 逾期机制

| 逾期天数 | 经济后果 | 信用评分 | 叙事信号 |
|:--------:|----------|:------:|----------|

## 二、四重斩杀线状态机

### 2.1 状态定义

每条斩杀线有5个状态：

```
SAFE → WARNING → DANGER → CRITICAL → TRIGGERED
安全     警戒      危险      临界       触发
```

### 2.2 经济斩杀线

| 状态 | 阈值 | 表现 | 效果 |
|------|:---:|------|------|
| SAFE | 净资产 > $5,000 | 银行App正常 | 无 |
| WARNING | $0 ~ $5,000 | 开始看账户余额 | 无 |
| DANGER | -$5,000 ~ $0 | 催款信（白色） | 贷款利率+2% |
| CRITICAL | -$10,000 ~ -$5,000 | 催款信（黄色）+电话 | 贷款利率+5%，消费选项减半 |
| TRIGGERED | < -$10,000（且连续3月） | 红色通知+强制执行 | 消费禁用，催收事件频率×2 |

**逆转条件**：连续2个月净资产改善 → 升一级

### 2.3 体力斩杀线

| 状态 | 阈值 | 表现 | 效果 |
|------|:---:|------|------|
| SAFE | > 70% | 睡醒有精神 | 无 |
| WARNING | 40-70% | 需要咖啡 | 加班收入-10% |
| DANGER | 10-40% | 失眠/疼痛 | 加班收入-30%，加班上限-5h |
| CRITICAL | 5-10% | 爬楼梯喘气 | 加班不可用，工作收入-20% |
| TRIGGERED | < 5% | 无法起床 | 收入归零，强制休息2月 |

**逆转条件**：体力恢复到25%以上 → 升一级

### 2.4 社交斩杀线

| 状态 | 阈值 | 表现 | 效果 |
|------|:---:|------|------|
| SAFE | > 60% | 有人约周末 | 无 |
| WARNING | 30-60% | 回复变慢 | 正面社交事件概率-10% |
| DANGER | 10-30% | 没人主动联系 | 正面社交事件概率-30%，婚姻压力+10% |
| CRITICAL | 5-10% | 电话簿已读不回 | 贵人事件禁用，婚姻破裂概率+20% |
| TRIGGERED | < 5%（且连续2次负面社交） | 被社交圈排斥 | 社交时间块效果减半，婚姻自动解除 |

**逆转条件**：连续2月无负面社交事件 → 升一级

### 2.5 存在斩杀线

| 状态 | 阈值 | 表现 | 效果 |
|------|:---:|------|------|
| SAFE | 全部文件有效 | 驾照+医保卡有效 | 无 |
| WARNING | 1项过期 | 收到更新提醒 | 无 |
| DANGER | 2项过期 | 医保暂停/驾照过期 | 医疗费用×2 |
| CRITICAL | 3项过期 | 身份验证失败 | 医疗费用×3，部分地点不可访问 |
| TRIGGERED | 全部失效 | 信件退回"查无此人" | 无法使用正规医疗/银行/住房系统 |

**逆转条件**：更新至少2项文件 → 升一级（需要$500-$2,000和特定事件触发）

### 2.6 四线交互

```
四线全在 SAFE/WARNING：正常游戏
任一线 DANGER：对应惩罚生效
任一线 CRITICAL：严重惩罚 + 全局事件概率+20%
任一线 TRIGGERED：对应维度崩溃
四线全 TRIGGERED → 「斩杀时刻」→ 游戏强制结束 → 结局C
```

## 四、月度结算流程

### 4.1 结算步骤

```
① 收入计算：工作 + 加班 + 灰色 + 被动 + 事件
② 支出计算：固定账单 + 意外 + 逾期罚款 + 事件
③ 净现金流 = 收入 - 支出
④ 净资产更新
⑤ 体力更新：上月体力 + 休息恢复 - 加班消耗 - 事件消耗
⑥ 社交值更新：上月社交 + 社交时间块效果 + 事件效果
⑦ 存在状态更新：检查文件过期状态
⑧ 斩杀线状态更新：四个维度各自判定状态转换
⑨ 显示结算界面（含角色独白）
```

### 4.2 结算界面规格

```
┌─────────────────────────────────────┐
│         📊 11月结算                  │
│         ═══════════                 │
│                                     │
│  💵 工作收入    +$2,200             │
│  🔥 加班收入    +$550               │
│  📉 固定支出    -$1,870             │
│  ⚡ 意外支出    -$200（热水器维修）    │
│  ─────────────────────             │
│  📊 净现金流    +$680               │
│  💰 净资产      $3,680              │
│                                     │
│  ❤ 体力        72/100 → 68/100     │
│  🤝 社交        65% → 68%           │
│                                     │
│  💬 "这个月还行。但下个月呢？"        │
│                                     │
│  🔴 斩杀线：                        │
│  经济🟢 体力🟡 社交🟢 存在🟢          │
│                                     │
│         [继续 → 12月]               │
└─────────────────────────────────────┘
```

### 4.3 结算时的角色独白

独白文本取决于：
- 本月净现金流（正/负/接近零）
- 斩杀线状态变化
- 角色身份（Voice Pillars）

示例（马库斯，净现金流+$680）：
> "这个月还行。$680进了储蓄。艾玛的圣诞礼物有着落了。但下个月——下个月有报税。"

示例（佐伊，净现金流-$200）：
> "又一个月。又少了$200。我的银行余额像沙漏。学贷$920。房租$650。$2,147。这些数字已经刻在我脑子里了。"
