## 一、事件与时间块的交互

### 1.1 事件触发时机

事件在玩家**确认时间块分配后**弹出。这故意制造"计划被打乱"的感觉。

```
玩家流程：
  ① 分配时间块 → ② [确认分配] → ③ 事件弹出 → ④ 重新调整 → ⑤ 月末结算
```

### 1.2 事件分类与时间块映射

叙事设计中的事件类型映射到玩法：

| 叙事事件类型 | 玩法消耗类型 | 时间块交互 |
|-------------|------------|-----------|
| 即时决策（E-NU系列） | 0h / $0 | 不消耗时间块，立即结算 |
| 时间消耗事件 | 2-8h | 从已分配的时间块中削减 |
| 金钱消耗事件 | $50-$5,000 | 直接扣款，余额不足触发借贷选项 |
| 复合消耗事件 | 时间+金钱 | 同时削减时间块和扣款 |
| 高压对峙事件（E-H系列） | 时间+高风险 | 削减时间块 + 概率触发后续事件 |

### 1.3 事件弹出的时间块调整UI

当事件需要时间时，显示调整界面：

```
┌──────────────────────────────────────────────┐
│ ⚡ 事件：艾玛的家长会                           │
│ "老师想见你。周四下午3点。"                      │
│                                              │
│ 需要时间：4小时                                │
│                                              │
│ 从哪个时间块削减？                              │
│                                              │
│ ○ 🔥 加班（当前15h → 11h）  收入-$220          │
│ ○ 😴 休息（当前8h → 4h）    体力恢复-20         │
│ ○ 🤝 社交（当前5h → 1h）    社交值增长-8        │
│ ○ 📚 学习（当前2h → 0h）    学历值增长-6        │
│ ○ 🕶 灰色（当前0h，不可削减）                   │
│                                              │
│ [拒绝事件] → 亲子关系-15，可能触发后续负面事件    │
└──────────────────────────────────────────────┘
```

### 1.4 拒绝事件的连锁后果

叙事设计中的"因果事件链"通过玩法实现：

```
拒绝E-N03「关系的裂痕」中的"弥补"选项
  ↓
下个月触发 E-N03-C「沉默的代价」
  ↓
社交斩杀线自动降一级
  ↓
未来3个月内社交事件选项减少50%
```

### 2.3 结算独白的Voice Pillars映射

每月结算时，独白文本从角色的Voice Pillars中动态选择：

```
规则：
  IF 净现金流 > $500 → 使用角色的"乐观"独白池
  IF 净现金流 -$200~$500 → 使用角色的"中性"独白池
  IF 净现金流 < -$200 → 使用角色的"焦虑"独白池
  IF 斩杀线状态变化 → 额外追加"斩杀线"独白
```

## 五、LXP与多周目系统

### 5.1 LXP计算

```
LXP = 基础通关 + 净资产奖励 + 角色首次通关 + 隐藏结局奖励

基础通关：任何结局 +100
净资产奖励：每$10K +5（上限500）
角色首次通关：+200
隐藏结局D：+500
```

### 5.2 "前世记忆"（多周目）

同一角色第二次玩时，触发"前世记忆"机制：

| 周目 | 变化 |
|:----:|------|
| 1周目 | 正常体验 |
| 2周目 | 部分事件出现额外选项（标注💭"你好像经历过这个……"） |
| 3周目+ | 起始现金+$2,000（"教训的价值"）+ 精通模式解锁 |

### 5.3 不同角色揭示不同世界侧面

叙事设计中定义的"多周目叙事差异"通过以下方式实现：

- 通关马库斯（#1）→ 解锁"底层劳动市场"知识库 → 其他角色在M-7物流中心的事件选项+1
- 通关安娜（#7）→ 解锁"移民系统"知识库 → 其他角色在移民相关事件中获得额外信息
- 通关凯瑟琳（#12）→ 解锁"学术兼职"知识库 → 其他角色的学习时间块效率+10%

## 六、观测者隐藏线的玩法实现

### 6.1 触发条件链

```
E-OB01 观测者第一封信
  触发条件：在至少3个月的时间块分配中选择了"学习"或拒绝了"灰色"
  含义：玩家在"质疑系统"——选择了非纯经济理性的策略
  
E-OB02 观测者第二封信
  触发条件：收集了特定信息（在E-N04「系统的信」中选择"走正式申诉流程"）
  含义：玩家开始理解系统的运作方式

E-OB03 观测者的邀请
  触发条件：E-OB01 + E-OB02 + 7月（斩杀线临界月）
  含义：观测者认为玩家"准备好了"

E-OB04 老铁厂遗址会面
  触发条件：E-OB03中选择"去"
  含义：解锁隐藏结局D路线

隐藏结局D
  触发条件：E-OB04完成 + 9月净资产≥$100K
```
