# 《斩杀线》UI/UX 详细规格 v1.0

> 视觉风格：PvZ漫画厚涂 × 西方社会现实主义
> 设计理念：**"打工人的漫画人生"** — 用诙谐夸张的视觉语言讲述残酷真实的社会隐喻
> 对齐：NarrativeDesigner v3.2 的PvZ风格 + GameDesigner v1.0 的时间块玩法

---

## 一、总体UI架构

### 1.1 界面层级

```
主菜单
  ├── 角色选择（三选一卡片）
  ├── 月度循环（核心游戏界面）
  │     ├── 时间块分配面板
  │     ├── 事件弹窗卡片
  │     ├── 账单列表
  │     ├── 斩杀线状态栏
  │     └── 月末结算界面
  ├── 结局结算界面
  └── LXP/解锁界面
```

### 1.2 色彩体系

对齐叙事设计的五世界主题色：

| 用途 | 色值 | 说明 |
|------|------|------|
| 💰 收入/正数 | `#4CAF50` | 绿色增长 |
| 📉 支出/负数 | `#F44336` | 红色警告 |
| ⚠ 警告 | `#FF9800` | 橙色警示 |
| 🔵 信息 | `#2196F3` | 蓝色中性 |
| ⚪ 背景底色 | `#F5F0E8` | 泛黄纸张色 |
| ⚫ 描边色 | `#1A1A2E` | 深蓝黑 |
| 🔴 斩杀线红 | `#FF1744` | 最刺眼的红色 |

### 1.3 字体层级

| 层级 | 字体 | 大小 | 用途 |
|------|------|:---:|------|
| H1 | **Bangers** | 48px | 标题、结局名 |
| H2 | **Fredoka One** | 32px | 月份、面板标题 |
| H3 | **Nunito Bold** | 24px | 按钮文字、角色名 |
| Body | **Nunito Regular** | 16px | 描述文本、事件正文 |
| Data | **JetBrains Mono** | 18px | 数字、金额 |
| Small | **Nunito Light** | 12px | 辅助说明 |

## 五、交互流程与动画

### 5.1 全局动效规范

| 元素 | 动效 | 时长 | 缓动 |
|------|------|:---:|------|
| 按钮按下 | 下沉 4px + 阴影缩小 | 0.1s | ease-in |
| 面板打开 | 从下方滑入 + 轻微弹跳 | 0.3s | ease-out-back |
| 数字变化 | 跳动 + 颜色闪烁 | 0.2s | ease-out |
| 斩杀线脉冲 | 红色光波扩散 | 0.5s | linear |
| 事件弹出 | 从右侧滑入 + 轻微震动 | 0.3s | ease-out-back |
| 滑块拖拽 | 实时平滑过渡 | 实时 | linear |

### 5.2 关键动画

**斩杀线状态变化**：
```
斩杀线状态下降时（如：安全→警戒）：
  → 对应行红色闪烁 0.3s
  → 叙事信号文本替换动画（旧文本淡出，新文本淡入）
  → 屏幕边缘短暂红色暗角（0.5s）
```

**月末结算数字跳动**：
```
净现金流数字逐个翻转（类似航班信息屏）
绿色向上，红色向下
最终数字确定时短暂放大+发光
```

## 六、平台适配

### 6.1 目标平台

| 平台 | 分辨率 | UI缩放 | 特殊适配 |
|------|--------|:-----:|----------|
| PC | 1920×1080 | 1.0x | 鼠标拖拽+悬停效果 |
| Steam Deck | 1280×800 | 0.85x | 触屏+手柄双模式 |
| 移动端(未来) | 自适应 | 0.7x | 竖屏模式，滑块放大到44px+ |

### 6.2 响应式设计

- 核心时间块面板在移动端堆叠为纵向布局
- 事件弹窗在移动端占满屏幕宽度
- 斩杀线状态栏在移动端折叠为一行，点击展开
