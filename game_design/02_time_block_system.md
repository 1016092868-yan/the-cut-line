# 《斩杀线》时间块分配系统详细规格 v1.0

---

## 一、系统概述

### 1.1 核心概念

时间块分配是《斩杀线》的**唯一核心操作**。玩家每月有120小时可用时间，通过拖拽滑块来分配6种时间块。60小时固定投入工作，剩余60小时在5种可选时间块之间分配。

### 1.2 设计目标

- **简单**：操作=拖拽滑块。5分钟学会。
- **有深度**：6种时间块的取舍创造策略空间。
- **有意义**：每次分配都是价值观选择——赚钱还是休息？社交还是学习？
- **有后果**：本月的时间分配影响2-3个月后的状态。

## 二、时间块详细规格

### 2.1 🏢 工作（固定60h）

```
类型：固定（不可调整）
投入：60小时/月
产出：角色时薪 × 60
约束：不可减少（这是"系统"给你的基线）
叙事含义："你没有选择。你必须工作。"
```

### 2.2 🔥 加班

```
类型：可选
投入：0-20小时/月
产出：角色时薪 × 1.5 × 投入小时
代价：体力 -3/小时
约束：体力<20%时不可加班
叙事含义："你在用身体换钱。你知道。但你需要钱。"
```

**逐小时效果表**：

| 加班小时 | 额外收入（时薪$36.67） | 体力消耗 |
|:--------:|:---------------------:|:------:|
| 5h | +$275 | -15 |
| 10h | +$550 | -30 |
| 15h | +$825 | -45 |
| 20h | +$1,100 | -60 |

### 2.3 🤝 社交

```
类型：可选
投入：0-15小时/月
产出：社交值 +2/小时 + 概率触发正面社交事件
风险：社交值<30%时，社交事件有概率被拒绝（-心情）
约束：无
叙事含义："关系需要维护。不维护就会生锈。"
```

**社交值效果**：

| 社交值范围 | 效果 |
|:---------:|------|
| >80% | 正面社交事件概率+20%，被拒绝概率0% |
| 50-80% | 正常概率 |
| 30-50% | 正面社交事件概率-10%，被拒绝概率20% |
| <30% | 正面社交事件概率-30%，被拒绝概率50% |

### 2.4 📚 学习

```
类型：可选
投入：0-10小时/月
产出：学历值 +3/小时 + 每10小时学习永久提升时薪$1
代价：短期无收入回报
约束：无
叙事含义："你在投资未来。但未来还没来。"
```

**学习累积效果**：

| 累计学习小时 | 永久时薪提升 |
|:----------:|:----------:|
| 10h | +$1.00/h |
| 30h | +$3.00/h |
| 60h | +$6.00/h |
| 100h | +$10.00/h（上限） |

### 2.5 😴 休息

```
类型：可选
投入：0-20小时/月
产出：体力 +5/小时
代价：收入机会成本（这些小时本可以用来加班）
约束：体力>90%时休息效率减半
叙事含义："休息不是偷懒。是投资。但账单不在乎。"
```

**体力恢复效果**：

| 休息小时 | 体力恢复 |
|:--------:|:------:|
| 5h | +25 |
| 10h | +50 |
| 15h | +75 |
| 20h | +100（满体力） |

### 2.6 🕶 灰色经济

```
类型：可选
投入：0-15小时/月
产出：$25/小时（固定）
风险：每月灰色小时>5h时，触发法律风险事件的概率 = 灰色小时×3%
约束：需要前置条件（接触过利奥）
叙事含义："当系统拒绝你时，这里有另一扇门。门后有代价。"
```

**风险概率表**：

| 灰色小时 | 月收入 | 风险触发概率 |
|:--------:|:------:|:----------:|
| 5h | +$125 | 15% |
| 10h | +$250 | 30% |
| 15h | +$375 | 45% |

**风险事件后果**：
- 轻度（60%概率）：收入减半，警告
- 中度（30%概率）：收入归零，社交-10
- 重度（10%概率）：触发执法事件，存在斩杀线逼近

### 3.2 交互规格

| 操作 | 行为 | 反馈 |
|------|------|------|
| 拖拽滑块向右 | 增加该时间块的投入小时 | 实时更新预估收入/体力变化/剩余时间 |
| 拖拽滑块向左 | 减少该时间块的投入小时 | 实时更新 |
| 超过剩余时间 | 滑块无法继续向右 | 滑块变红，提示"时间不足" |
| 点击[确认分配] | 锁定本月分配 | 进入事件阶段 |
| 事件要求时间 | 弹出"需要X小时，从哪个块调整？" | 高亮可调整的时间块 |

### 3.3 约束与边界

```
总约束：工作(60h) + 加班(0-20h) + 社交(0-15h) + 学习(0-10h) + 休息(0-20h) + 灰色(0-15h) ≤ 120h

独立上限：
  加班 ≤ 20h（体力<20%时 ≤ 0h）
  社交 ≤ 15h
  学习 ≤ 10h
  休息 ≤ 20h（体力>90%时效率减半）
  灰色 ≤ 15h（需要前置：接触过利奥）

特殊约束（角色特定）：
  伊桑(#9)：工作60h可替换为灰色时间
  西蒙(#15)：体力上限65%，加班上限10h
  艾琳&马克(#10)：社交上限20h（双人社交加成）
  特伦斯(#18)：工作收入为$0（无工作技能），灰色不可用
```

## 四、时间块与事件的冲突解决

### 4.1 冲突发生机制

事件在时间块分配**确认后**弹出。事件可能要求额外的时间投入。玩家必须从已分配的时间块中重新分配。

### 4.2 冲突解决流程

```
① 事件弹出：显示事件内容 + 所需时间/金钱
② 如果事件需要时间：
   → 显示当前分配 + 高亮"可削减"的时间块
   → 玩家选择从哪个块削减
   → 确认后，事件时间从该块扣除
③ 如果事件需要金钱：
   → 直接扣除（如果余额足够）
   → 如果余额不足 → 触发"借贷"选项或"忽略"后果
④ 如果玩家选择"拒绝事件"：
   → 触发事件的"拒绝后果"
```

### 4.3 冲突示例

```
事件：艾玛的家长会（需要4h）

当前分配：工作60h | 加班15h | 社交5h | 学习2h | 休息8h | 灰色0h

玩家选择：
  A. 从加班削减4h → 加班变11h，收入减少$220
  B. 从休息削减4h → 休息变4h，体力恢复减少20
  C. 从社交削减4h → 社交变1h，社交值增长减少
  D. 拒绝事件 → 亲子关系-15，可能触发后续负面事件
```
