# 《斩杀线》新手引导 + 资产/婚姻/育儿 + 主动策略系统 v1.1

> 关键优化：逐月解锁引导 + 资产购买玩法 + 婚姻育儿互动 + 玩家主动触发事件

## 一、新手引导系统

### 1.1 设计理念

引导不是教程关卡——是**逐月解锁系统复杂度**。玩家不会在10月面对全部6个时间块。

### 1.2 逐月解锁表

| 月份 | 解锁内容 | 引导方式 |
|:----:|----------|----------|
| **10月** | 工作(60h) + 休息(0-20h) | 只有2个滑块。旁白："这个月，你只需要工作。和休息。" |
| **11月** | + 加班(0-20h) | 旁白："感恩节快到了。你需要更多钱。加班吗？" + 闪烁的加班滑块 |
| **12月** | + 社交(0-15h) | 旁白："圣诞节。朋友在约你。去吗？" + 第一个社交事件（强制） |
| **1月** | + 学习(0-10h) | 旁白："新年。你想学点什么吗？" |
| **2月** | + 灰色(0-15h) | 利奥首次接触事件（强制）后解锁 |
| **3月+** | 全部系统 | 不再有引导 |

### 1.3 首次操作引导

**10月第一次时间块分配**：
```
┌──────────────────────────────────────────────┐
│  📅 2024年10月 — 你的第一个月                   │
│──────────────────────────────────────────────│
│                                              │
│  这是你的时间。120小时。                         │
│                                              │
│  🏢 工作 60h ← 这是固定的。你必须工作。           │
│                                              │
│  😴 休息 20h ← 拖拽滑块来调整。                  │
│     ████████░░░░░░░░░░░░ 10h                  │
│     ← 0h ────────────── 20h →                 │
│     💡 试试拖动这个滑块                          │
│                                              │
│  剩余：50小时（下个月解锁更多选择）                │
│                                              │
│  [确认分配]                                    │
└──────────────────────────────────────────────┘
```

### 1.4 进阶策略提示（非强制）

第5个月起，结算界面偶尔出现"策略提示"——以角色独白形式：

```
💡 "也许我该少加点班，多休息。体力一直在降。"
💡 "学了三个月了。时薪涨了$3。值不值？"
💡 "利奥又联系我了。上次的活儿——还行。但下次呢？"
```

## 二、资产购买系统

### 2.1 购买流程

资产购买不是"商店"——通过事件触发：

```
事件触发（如"隔壁在卖房"）→ 显示资产详情 → 选择购买/观望/拒绝
  ↓ 购买
扣除首付 + 贷款审批（信用评分检查）→ 获得资产
  ↓ 每月
月维护费自动扣除 + 年末资产重估值
```

### 2.2 资产购买事件设计

**E-ASSET-01：「隔壁在卖」**
```
触发条件：3月后 + 净资产≥$5K + 社区连接≥1
类型：资产机会

叙事：
  玛格丽特敲了你的门。"隔壁的约翰逊太太要搬去养老院。
  她的公寓在卖。不贵。$40,000。首付$5,000。
  我认识卖房经纪——可以帮你谈谈。"

选项：
  A. 购买（-$5,000首付，+$35,000贷款，月供$300）
  B. "我需要时间考虑。"（资产机会保留到下个月）
  C. "我买不起。"（资产机会消失，可能未来再次出现）
```

**E-ASSET-02：「法拍房」**
```
触发条件：6月后 + 净资产≥$15K + 接触过格洛丽亚
类型：资产机会

叙事：
  格洛丽亚在银行窗口后压低声音。
  "有一个法拍房。中环。$120,000。首付$15,000。
   银行想尽快出手。我可以帮你加速审批。"

选项：
  A. 购买（-$15,000首付，+$105,000贷款，月供$600）
  B. "风险太大了。"
  C. "我只有$10,000。"（触发特殊选项：格洛丽亚帮你争取低首付）
```

### 2.3 资产年末重估值

第12月结算时，所有资产按年增值率重估：

```
南岸公寓：买入$40K → 增值5% → 现值$42K
中环联排：买入$120K → 增值10% → 现值$132K
指数基金：买入$5K → 波动+8% → 现值$5.4K

净资产 = 现金 + (资产现值 - 剩余贷款)
```

## 三、婚姻与育儿互动系统

### 3.1 婚姻不是账单——是月度互动

婚姻不只是账单上的$300维护费。每月结算时，如果已婚，额外出现"伴侣互动"：

```
┌──────────────────────────────────────────────┐
│  💍 本月婚姻互动                               │
│──────────────────────────────────────────────│
│                                              │
│  玛丽亚注意到你这周回家很晚。                     │
│                                              │
│  ○ 早点回家陪她（-4h加班，+婚姻关系）             │
│  ○ 解释原因（+可能理解，-可能失望）               │
│  ○ 忽略（-婚姻关系，累计3次触发婚姻危机）          │
└──────────────────────────────────────────────┘
```

**婚姻状态追踪**：

| 婚姻关系值 | 状态 | 效果 |
|:---------:|------|------|
| >80% | 稳固 | 双人加成：社交时间块效果×1.2 |
| 50-80% | 正常 | 无特殊效果 |
| 30-50% | 紧张 | 每月额外出现婚姻压力事件 |
| <30% | 危机 | 可能触发离婚事件 |

### 3.2 育儿不是账单——是月度事件

育儿不只是$400-$800的账单。每月结算时，如果有孩子，额外出现"育儿时刻"：

```
┌──────────────────────────────────────────────┐
│  👶 本月育儿时刻                               │
│──────────────────────────────────────────────│
│                                              │
│  艾玛的数学下降了。老师建议补习。                  │
│                                              │
│  ○ 花钱请补习（-$200，+艾玛成绩）                │
│  ○ 自己辅导（-4h时间块，+亲子关系）               │
│  ○ "她会自己赶上的。"（-亲子关系）               │
└──────────────────────────────────────────────┘
```

**育儿追踪**：

| 亲子关系值 | 状态 | 效果 |
|:---------:|------|------|
| >80% | 亲密 | 每月额外+5体力（情感支撑） |
| 50-80% | 正常 | 无特殊效果 |
| 30-50% | 疏远 | 育儿事件选项减少 |
| <30% | 危机 | 触发"前妻争取完全抚养权"事件 |

## 四、玩家主动策略系统

### 4.1 设计理念

原设计中所有事件都是被动弹出的。玩家需要**主动触发**的策略选项。

### 4.2 主动行动面板

每月在时间块分配界面底部增加一个**"主动行动"**按钮：

```
┌──────────────────────────────────────────────┐
│  🎯 主动行动（本月可使用1次）                    │
│──────────────────────────────────────────────│
│                                              │
│  ○ 📞 联系旧友（消耗2h社交，可能触发机会）        │
│  ○ 🔍 寻找副业（消耗5h，下月可能解锁额外收入）     │
│  ○ 🏦 申请贷款（消耗2h，获得贷款选项）            │
│  ○ 📝 更新简历（消耗3h，可能触发面试事件）         │
│  ○ 🕶 联系利奥（消耗1h，主动触发灰色经济机会）     │
│  ○ 🤝 帮助邻居（消耗3h，+社区连接）              │
│                                              │
│  本月剩余主动行动次数：1                          │
└──────────────────────────────────────────────┘
```

### 4.3 主动行动的设计约束

- 每月仅1次（防止滥用）
- 每次消耗时间——从已分配的时间块中扣除
- 结果不确定——可能成功、可能失败、可能引发意外
- 部分行动需要前置条件（如"联系利奥"需要先触发利奥首次接触事件）

### 4.4 主动行动的效果表

| 行动 | 消耗 | 成功效果 | 失败效果 | 成功概率 |
|------|:----:|----------|----------|:------:|
| 联系旧友 | 2h社交 | 下月触发正面社交事件 | 无效果 | 70% |
| 寻找副业 | 5h | 下月解锁$200-500/月额外收入 | 浪费5h | 50% |
| 申请贷款 | 2h | 获得贷款选项（金额取决于信用） | 信用评分-3 | 80% |
| 更新简历 | 3h | 下月触发面试事件 | 无效果 | 60% |
| 联系利奥 | 1h | 触发灰色经济机会 | 利奥拒绝（"现在没活儿"） | 60% |
| 帮助邻居 | 3h | +社区连接，可能触发社区回报 | 无效果（但+社交值） | 90% |

## 五、独特记忆点：「斩杀时刻」

### 5.1 概念

当任一条斩杀线触发时，不是静默的状态变化——而是一个**全屏事件**。

### 5.2 斩杀时刻的呈现

```
[屏幕突然变红。所有UI元素染上红色。]

[时间块分配界面被"冻结"——所有滑块锁定3秒。]

[屏幕中央出现大字：]

┌──────────────────────────────────────────┐
│                                          │
│           🔴 斩杀线触发                    │
│                                          │
│      "你的净资产跌破-$10,000。              │
│       连续3个月无改善。                     │
│       系统收回了它的善意。"                 │
│                                          │
│      [承受后果]                            │
└──────────────────────────────────────────┘

[3秒后，UI恢复正常。但斩杀线状态栏永久多了一个红色标记。]
[角色独白在结算时改变：声音更疲惫、句子更短。]
```

### 5.3 设计意图

"斩杀时刻"是游戏的独特记忆点——玩家会记住第一次看到全屏变红的瞬间。它不频繁（一局可能1-2次），但每次都有重量。

## 六、新手引导到精通的学习曲线

| 周目 | 玩家状态 | 引导强度 | 解锁内容 |
|:----:|----------|:------:|----------|
| 第1局 | 新手 | 逐月解锁+首次操作引导+策略提示 | 角色1-6 |
| 第2-3局 | 进阶 | 仅策略提示（可关闭） | 角色7-13 |
| 第4-6局 | 熟练 | 无引导 | 角色14-20 |
| 第7局+ | 精通 | 挑战模式 | 隐藏模式「人间百态」 |
