## 四、斩杀线UI元素

### 4.1 四重斩杀线图标

| 斩杀线 | 图标 | 颜色 |
|--------|------|:----:|
| 💰 经济斩杀线 | 破碎的硬币 | `#F44336` |
| ❤ 体力斩杀线 | 心率线+裂纹 | `#FF5252` |
| 🤝 社交斩杀线 | 断开的人像连线 | `#FF8A80` |
| 📋 存在斩杀线 | 撕裂的身份文件 | `#D50000` |

### 4.2 斩杀线状态指示灯

```
🟢 SAFE：   饱满的绿色圆形 + 发光
🟡 WARNING：黄色圆形 + 脉冲
🟠 DANGER： 橙色圆形 + 快速脉冲
🔴 CRITICAL：红色圆形 + 快速脉冲 + 暗角
💀 TRIGGERED：骷髅图标 + 全屏红色
```

### 4.3 「斩杀时刻」全屏效果

```
层级1：屏幕边缘红色暗角（从外向内渐进）
层级2：斩杀线大字（"🔴 CUT LINE TRIGGERED"）——粗黑描边+红色填充
层级3：UI冻结（所有滑块锁定3秒）
层级4：角色红色轮廓光
层级5：红色粒子从右侧飘入
```

## 五、事件弹窗卡片视觉

### 5.1 卡片规格

```
尺寸：600×400px（弹窗）
风格：粗黑描边4px + 圆角16px + 漫画气泡风格
背景：泛黄纸张色 #F5F0E8（带Canvas纹理——微弱的咖啡渍+折痕）
```

### 5.2 事件类型颜色编码

| 事件类型 | 卡片顶部色条 | 图标 |
|----------|:----------:|------|
| 正面事件 | `#66BB6A` 绿 | 🎉 |
| 负面事件 | `#F44336` 红 | ⚠ |
| 中性事件 | `#FFB74D` 橙 | 💬 |
| 高压事件 | `#D50000` 深红 | 🔴 |
| 灰色事件 | `#7B1FA2` 暗紫 | 🕶 |
| 季节事件 | `#42A5F5` 蓝 | 📅 |
| Boss事件 | `#000000` 黑+红脉冲 | 💀 |

### 5.3 选项按钮

```
尺寸：自适应宽度（最小200px），高48px
风格：粗黑描边3px + 圆角8px
颜色：
  🟢 安全选项：浅绿填充 #C8E6C9
  🟡 风险选项：浅黄填充 #FFF9C4
  🔴 危险选项：浅红填充 #FFCDD2
悬停：下沉2px + 阴影加深
```

## 六、结算界面视觉元素

### 6.1 收入/支出指示器

```
收入：绿色向上箭头 + 数字跳动动画（类似航班信息屏翻转）
支出：红色向下箭头 + 数字跳动动画
净现金流：大号数字 + 绿色（正）/红色（负）+ 发光
```

### 6.2 斩杀线状态条

```
水平条：宽度100%，高度8px
颜色渐变：绿→黄→橙→红
当前状态：白色竖线指示器
变化动画：白色竖线平滑移动 + 颜色过渡
```

### 6.3 角色独白气泡

```
风格：漫画对话气泡（尖角指向角色头像）
背景：白色 + 粗黑描边2px
字体：Nunito Regular 16px
位置：结算界面底部
```

## 七、货币与数值显示

### 7.1 货币格式

```
正数：$1,370（绿色 #4CAF50）
负数：-$340（红色 #F44336）
零：$0（灰色 #9E9E9E）
字体：JetBrains Mono 18px（等宽——数字对齐）
```

### 7.2 数值变化动画

```
增加：数字向上翻转 + 绿色闪烁 0.3s
减少：数字向下翻转 + 红色闪烁 0.3s
大幅变化（>20%）：数字放大110% + 发光 0.5s
```
