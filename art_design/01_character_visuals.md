# 《斩杀线》角色视觉设计 v1.0

> ArtDirector | 基于 NarrativeDesigner v3.2 + GameDesigner v1.1
> 视觉风格：PvZ漫画厚涂 × 西方社会现实主义
> 设计理念：**"打工人的漫画人生"** — 粗黑描边、夸张特征、状态可见

---

## 一、视觉设计原则

### 1.1 风格DNA

```
PvZ基因：粗黑描边3px、扁平色块、夸张表情、卡片式呈现
《斩杀线》独有：粗粝质感（纸张纹理/咖啡渍）、霓虹点缀、斩杀线红光
```

### 1.2 角色设计原则

1. **种族多样性** — 20角色覆盖白人/黑人/拉丁裔/亚裔/中东裔/混血
2. **体型多样性** — 瘦高/健壮/丰满/矮小/残障
3. **着装即叙事** — 衣服讲述职业和状态（西装→白领、工装→蓝领、围裙→服务业）
4. **状态可读** — 体力/情绪通过面部和姿态直接传达
5. **斩杀线可见** — 接近斩杀线时，角色出现红色轮廓光

### 1.3 角色卡片规格

```
尺寸：512×768px（竖版卡片）
风格：粗黑描边半身像 + 角色名 + 一句话标签
背景：角色所在区域的环境色
边框：3px粗黑描边 + 16px圆角
```

### 5.1 夸张特征设计意图

- **缩略图可辨识**：即使128×128px，夸张特征让角色一眼可辨
- **PvZ风格核心**：不是写实——是漫画。眼袋可以放硬币、手表比脸大、四叶草长在头上
- **叙事增强**：夸张特征本身就是叙事——"42年的疲惫装在里面"
