## 一、Boss关全屏演出视觉规格

### 1.1 需求来源

关卡设计定义了3个Boss关，各有"全屏演出"需求：

| Boss关 | 主题 | 情感 | 关卡要求 |
|:------:|------|------|----------|
| 4月 | 清算 | 无力感 | "信封打开动画" |
| 7月 | 临界 | 恐惧 | "全屏红色脉冲" |
| 9月 | 锁定 | 决绝 | "路线专属全屏演出" |

### 1.2 4月Boss「清算」— 信封打开动画

```
视觉规格：
  尺寸：全屏1920×1080 overlay
  触发：Boss事件阶段2「结果揭晓」
  时长：2.5秒

动画序列：
  0.0s — 屏幕变暗50%
  0.3s — 一个巨大的信封从画面中央出现（白色/黄色/红色——取决于结果）
        白色=退税 | 黄色=补税 | 红色=审计
  0.8s — 信封撕开（锯齿状撕裂动画——粗黑描边风格）
  1.2s — 信封内的数字飞出：
         退税：绿色数字向上飘（+$500~$3,000）
         补税：红色数字向下坠（-$500~$2,000）
         审计：红色大字"AUDIT" + 破碎的放大镜图标
  1.8s — 数字在画面中央定格，放大，发光
  2.0s — 屏幕恢复，数字留在结算界面

风格：
  PvZ漫画厚涂——信封有粗黑描边4px，撕裂边缘是锯齿状（不是平滑的）
  退税信封：浅绿色 + 金色封蜡
  补税信封：浅黄色 + 红色"URGENT"印章
  审计信封：深红色 + 黑色"IRS"标记 + 封条
```

### 1.3 7月Boss「临界」— 全屏红色脉冲

```
视觉规格：
  尺寸：全屏1920×1080 overlay
  触发：Boss事件阶段1「斩杀线扫描」完成时
  时长：3秒（含1秒冻结）

动画序列：
  0.0s — 屏幕边缘出现红色暗角（从外向内）
  0.5s — 红色脉冲波从右侧袭来（斩杀线的方向）
         脉冲波是粗黑描边的红色同心圆——PvZ风格
  1.0s — 脉冲波经过角色——角色被红色轮廓包裹
  1.5s — 屏幕中央出现大字：
         "CUT LINE APPROACHING"
         Bangers字体 72px，粗黑描边+红色填充+发光
  2.0s — 大字破碎（像玻璃碎裂——PvZ夸张风格）
  2.5s — 碎片飘落，屏幕恢复
  3.0s — UI恢复，但斩杀线状态栏永久多一个红色标记

风格：
  红色脉冲波不是写实的光波——是PvZ风格的粗黑描边同心圆
  大字破碎不是CG——是漫画式的"碎裂线"
  整个过程有轻微的屏幕震动
```

### 1.4 9月Boss「锁定」— 路线专属全屏演出

三条路线有不同的全屏演出：

#### 合规路线：「门打开了」

```
动画序列：
  0.0s — 屏幕变暗
  0.5s — 一扇巨大的门从画面中央出现（粗黑描边——PvZ风格）
         门上写着"COMPLIANCE"（合规）
  1.0s — 门缓缓打开——门后是暖黄色的光
  1.5s — 光中的剪影：社区信用合作社、格洛丽亚的微笑、玛格丽特的汤
  2.0s — 门完全打开，光照亮整个画面
  2.5s — 屏幕恢复

色调：暖黄色 #FFD54F
情感：希望——但带着疲惫
```

#### 灰色路线：「阴影中的门」

```
动画序列：
  0.0s — 屏幕变暗
  0.5s — 南温斯顿街1147号的门从画面中央出现
         门上有那行小字："当系统拒绝你时，这里还有一扇门"
  1.0s — 门打开——门后是阴影
  1.5s — 利奥的剪影站在阴影中，不笑
  2.0s — 门开始关闭——但留了一条缝
  2.5s — 屏幕恢复

色调：暗紫色 #7B1FA2
情感：安全感与不安的混合
```

#### 觉醒路线（隐藏）：「观测者的笔记本」

```
动画序列：
  0.0s — 屏幕变暗
  0.5s — 观测者的旧笔记本从画面中央出现
         翻开——上面写满了观测记录
  1.0s — 笔记本的某一页被撕下——飘向玩家
  1.5s — 纸上的字："现在你知道了。你要怎么做？"
  2.0s — 纸变成一只鸟——飞向天空
  2.5s — 屏幕恢复，但天空中出现了一道微小的裂缝（暗示系统可以被改变）

色调：月光银 #CFD8DC + 天空蓝渐变
情感：愤怒转化为行动力
```

## 二、角色住所场景设计（3种）

### 2.1 需求来源

关卡设计中10月/1月/4月的场景是"角色住所"。不同角色住在不同区域。

### 2.2 🏠 南岸廉价公寓（马库斯/安娜/卢娜/奥斯卡等）

```
色调：暖黄灯光 #FFE0B2 + 旧砖棕 #8D6E63 + 暗影灰 #757575

构图：
  前景：小厨房——台面上有账单（最上面那封是红色的），旧咖啡机
  中景：客厅——二手沙发（有凹陷），墙上有一张艾玛的照片（马库斯）
        或十字架（安娜），或平台App截图（卢娜）
  后景：窗户——可以看到对面公寓的灯灭了（邻居搬走了？）
  细节：门上的驱逐通知（如果住房斩杀线接近）

夸张焦点：
  📬 门上的通知越来越大——从便签→A4→海报大小（PvZ夸张）
  
关键视觉细节：
  - 冰箱嗡嗡响——但里面是空的（经济斩杀线信号）
  - 墙上的照片/画——什么时候被取下来了？
  - 门锁——被换过吗？
  - 窗外的景色——对面公寓有人搬走了，灯灭了，再也没亮起

氛围变化（斩杀线逼近）：
  安全：暖黄灯光，窗外有对面的灯光
  警戒：冰箱嗡嗡声变大，对面的灯灭了一盏
  危险：驱逐通知出现在门上（白色→黄色→红色）
  临界：暖气不足，哈气可见
```

### 2.3 🏡 中环普通公寓（佐伊/德里克/艾玛/瑞秋等）

```
色调：中性灰 #F5F5F5 + 暖木棕 #A1887F + 绿植点缀 #66BB6A

构图：
  前景：书桌/餐桌——上面有笔记本电脑（佐伊改简历）、
        或健身器材（德里克）、或三件衬衫叠放整齐（艾玛）
  中景：客厅——宜家家具，书架上有大学教科书
  后景：阳台/窗户——可以看到中环的街景
  细节：冰箱上有外卖菜单和信用合作社的便签

夸张焦点：
  📚 书桌上的账单/简历/书本堆成比萨斜塔（PvZ夸张）
  
关键视觉细节：
  - 佐伊：三份简历并排——每一份都被划掉了
  - 德里克：墙上的比赛照片——奖杯在角落积灰
  - 艾玛：衣柜开着——里面只有三件衬衫（"够了"）
  - 瑞秋：地上有孩子的玩具——踩到了会响

氛围变化（斩杀线逼近）：
  安全：整洁，阳光从窗户照进来
  警戒：开始有未洗的碗
  危险：账单堆在桌上，最上面那封是黄色的
  临界：窗帘拉上了——"不想让邻居看到"
```

### 2.4 🏰 北岸联排/高级公寓（艾琳&马克/特伦斯/杰森/维多利亚等）

```
色调：冷白 #ECEFF1 + 大理石 #CFD8DC + 奢侈金 #FFD54F

构图：
  前景：开放式厨房——大理石台面，咖啡机是$500的（不是旧咖啡机）
  中景：客厅——设计师沙发，墙上挂着艺术品（不是海报）
  后景：落地窗——可以看到北岸天际线
  细节：智能家居设备在闪烁

夸张焦点：
  💸 特伦斯：客厅中央有一个巨大的信托基金存钱罐——
       透明的，可以看到里面的钱在减少（PvZ夸张）
  💍 艾琳&马克：狗贝利的豪华狗窝占客厅1/3——比大多数人的公寓还大

关键视觉细节：
  - 特伦斯：信用卡账单散落在$5,000的沙发上——他从未打开过
  - 艾琳&马克：双人工作台——两台iMac并排
  - 杰森：墙上不是画——是名片拼成的马赛克
  - 维多利亚：祖父的照片在壁炉上——她每次经过都会看一眼

氛围变化（斩杀线逼近）：
  安全：一切整洁，灯光温暖
  警戒：某个智能设备在闪红灯
  危险：特伦斯的信托基金存钱罐出现了裂缝
  临界：灯光开始闪烁——即使是北岸，电力也不稳定
```

## 三、观测者特殊消息UI样式

### 3.1 需求来源

UI/UX规格 Phase 3明确要求"观测者特殊消息样式"。

### 3.2 观测者消息卡片

```
┌──────────────────────────────────────────────────┐
│  ████████████████████████████████████████████████  │
│  ████████████ OBSERVER MESSAGE ██████████████████  │
│  ████████████████████████████████████████████████  │
│                                                  │
│  你被观测到了。                                    │
│                                                  │
│  不是政府。不是银行。                               │
│  我是一个观测者。                                   │
│                                                  │
│  这封信不是帮助。帮助是一种交易。                     │
│  这封信是——确认。                                  │
│                                                  │
│  你的怀疑是对的。                                  │
│                                                  │
│  —— OBS-47-2024                                 │
│                                                  │
│  ████████████████████████████████████████████████  │
│              [保留]        [删除]                  │
└──────────────────────────────────────────────────┘

设计规格：
  尺寸：500×400px
  背景：深色终端风格 #1E1E1E
  文字：JetBrains Mono 16px（等宽——像加密消息）
       颜色 #00FF41（绿色终端文字——像Matrix）
  边框：不是粗黑描边——是像素化的边框（2px虚线 #00FF41）
  顶部/底部：像素化条纹——像老式CRT显示器的扫描线
  动画：消息出现时有打字机效果（逐字显示，0.05s/字）
       保留/删除按钮在消息完全显示后才出现

与常规事件卡片的区别：
  常规卡片：粗黑描边+泛黄纸张+漫画气泡——温暖、有人味
  观测者消息：像素边框+终端绿字+扫描线——冷、匿名、系统感
  
  这种视觉对比本身就是叙事——观测者来自"系统的内部"
```
