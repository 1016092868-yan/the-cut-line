## 一、视觉风格指南

### 1.1 风格DNA

```
PvZ基因（60%）：
  ├── 粗黑描边（3px，关键元素4px）
  ├── 扁平色块（无渐变，纯色填充）
  ├── 夸张特征（角色特征放大——大学霸的超大眼镜、工人的粗壮手臂）
  ├── 卡片式呈现（角色卡片、事件卡片、资产卡片）
  └── 漫画情绪气泡（😱裁员！🎉升职！💔离婚...）

《斩杀线》独有基因（40%）：
  ├── 粗粝质感（Canvas纹理——纸张、咖啡渍、折痕、铁锈）
  ├── 斩杀线红光（贯穿所有UI的红色视觉锚点——#FF1744）
  ├── 城市对比（北岸冷白 vs 南岸暖黄 vs 中环中性灰）
  └── 状态可见（角色的体力/情绪/斩杀线距离通过视觉直接传达）
```

### 1.2 色彩体系

#### 主色调

| 用途 | 色值 | 说明 |
|------|------|------|
| 💰 收入/正数 | `#4CAF50` | 绿色增长 |
| 📉 支出/负数 | `#F44336` | 红色警告 |
| ⚠ 警告 | `#FF9800` | 橙色警示 |
| 🔵 信息 | `#2196F3` | 蓝色中性 |
| ⚪ 背景底色 | `#F5F0E8` | 泛黄纸张色 |
| ⚫ 描边色 | `#1A1A2E` | 深蓝黑（不是纯黑） |
| 🔴 斩杀线红 | `#FF1744` | 最刺眼的红色 |

#### 区域色调

| 区域 | 色温 | 主色 | 氛围 |
|------|:----:|:----:|------|
| 北岸 | 冷 | `#ECEFF1` | 大理石+玻璃——干净但冷漠 |
| 中环 | 中 | `#F5F5F5` | 混凝土+荧光灯——功能性的 |
| 南岸 | 暖 | `#FFE0B2` | 旧砖+暖黄灯光——破旧但有人味 |

### 1.4 视觉层次

```
第一层（最重要）：斩杀线红光 + 净资产数字 + 体力条
第二层（重要）：时间块分配面板 + 事件弹窗
第三层（辅助）：账单列表 + 结算浮层 + 角色独白
第四层（氛围）：场景背景 + 飘落粒子 + 环境动画
```

### 1.5 动画原则

| 原则 | 说明 |
|------|------|
| 按钮按下 | 下沉4px + 阴影缩小（0.1s ease-in） |
| 面板打开 | 从下方滑入 + 轻微弹跳（0.3s ease-out-back） |
| 数字变化 | 跳动 + 颜色闪烁（0.2s ease-out） |
| 斩杀线脉冲 | 红色光波扩散（0.5s linear） |
| 事件弹出 | 从右侧滑入 + 轻微震动（0.3s ease-out-back） |
| 滑块拖拽 | 实时平滑过渡（实时 linear） |
