### 2.2 夸张焦点的设计意图

- **PvZ风格核心**：不是写实——是漫画。排队像蛇、包裹堆成山、咖啡机比人大。
- **视觉记忆点**：每个场景有一个"一眼记住"的元素。
- **叙事浓缩**：夸张焦点浓缩了场景的叙事核心——银行=不平等（蛇形排队）、物流中心=无尽劳动（包裹山）、急诊室=等待（巨型钟）。

## 四、P0资产清单调整

### 问题
原P0清单中马库斯只有1种状态（idle），无法在原型阶段测试状态变化系统。

### 修正

P0阶段调整为包含马库斯的**4种状态**（体力充沛/疲惫/透支/濒危），确保原型可测试核心的状态变化机制：

| 资产 | 数量（旧） | 数量（新） | 说明 |
|------|:------:|:------:|------|
| 马库斯角色半身像 | 1 | **4** | +3状态变化（体力充沛/疲惫/透支/濒危） |
| 场景背景 | 1 | **1** | M-7物流中心（不变） |
| 场景氛围变化 | 0 | **4** | +4斩杀线状态overlay（警戒/危险/临界/触发） |
| 时间块图标 | 6 | **12** | +6色盲模式备选 |
| 斩杀线状态指示灯 | 5 | **5** | 不变 |
| 事件弹窗模板 | 3 | **3** | 不变 |
| 账单图标 | 7 | **7** | 不变 |
| UI通用图标 | ~10 | ~10 | 不变 |
| 按钮模板 | 4 | **4** | 不变 |
| **P0总计** | **~37** | **~50** | +13个资产 |

P0调整后的工期：2-3周 → **3-4周**（增加状态变化和色盲备选的工作量）

## 五、场景景深技术规格

2D界面中实现"远中近三层景深"的技术方案：

### 5.1 视差滚动方案

```
层级（从远到近）：
  后景（天空/远处建筑）— 移动速度 0.1x（几乎不动）
  中景（主要建筑/人群）— 移动速度 0.3x
  前景（UI元素/角色）— 移动速度 1.0x（正常）

实现：CSS transform: translateX() 或 Canvas分层渲染
触发：玩家在场景间切换时（月份切换），三层以不同速度平移
```

### 5.2 场景切换动画

```
月份切换 → 场景过渡动画（0.5s）：
  ① 前景先平移出（0.15s）
  ② 中景平移出（0.15s）
  ③ 后景平移出（0.15s）
  ④ 新场景后景平移入（0.15s）
  ⑤ 新场景中景平移入（0.15s）
  ⑥ 新场景前景平移入（0.15s）
  ⑦ 斩杀线overlay重新计算位置
```

## 六、角色在场景中的呈现规格

### 6.1 角色在场景中的位置

```
场景背景（全屏1920×1080）
  ├── 斩杀线overlay（右侧，根据状态变化宽度）
  ├── 角色半身像（左下角，400×600px区域）
  │     └── 角色状态变化动画（实时反映体力/情绪）
  ├── NPC（如果该场景有NPC——在场景中景位置）
  └── UI层（顶部状态栏 + 底部操作栏）
```

### 6.2 角色-场景交互

当场景切换时，角色半身像的**背景色渐变**以匹配新场景的色调——但角色本身保持不变（保持辨识度）。
