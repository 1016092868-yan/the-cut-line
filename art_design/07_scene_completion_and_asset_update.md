## 一、新增：感恩节家庭聚会场景（第12个场景）

### 1.1 需求来源

关卡设计：11月固定事件E-S01感恩节晚餐。场景-月份映射表中标注为"家庭聚会场景（通用）"但无独立视觉定义。

### 1.2 感恩节家庭聚会

```
位置：通用（根据角色可能是北岸/中环/南岸的住宅）
叙事功能：社交压力测试——"你如何向家人解释你的处境"
出现月份：11月
色调：暖橙 #FFB74D + 南瓜金 #FFD54F + 烛光黄 #FFF9C4

构图：
  前景：餐桌——火鸡在中央（烤焦了——"第一次做"），
        周围是各种感恩节菜肴（有人带了超市买的派——"没时间做"）
  中景：围坐的家人——有人在笑，有人在看你，有人在看手机
        亲戚A（举着酒杯）："所以——你现在在做什么？"
        亲戚B（在角落）：小声对旁边的人说"他看起来不太好"
  后景：厨房——还有人在忙碌，烤箱在冒烟
  细节：桌上的账单被匆忙塞到餐巾下面——但角还露在外面

夸张焦点：
  🦃 火鸡比桌子还大——"烤了8小时。还是生的。"
     PvZ夸张：火鸡大到需要两个人抬，但仍然烤焦了

关键视觉细节：
  - 餐桌上的话题——写在漫画气泡里：工作/收入/婚姻/孩子——都是压力
  - 某个亲戚的盘子里——食物堆成山（"多吃点——你太瘦了"=你看起来不好）
  - 窗外的M-7高速公路——即使感恩节也在堵车
  - 角落里的空椅子——有人没来（离婚/疏远/太远）

氛围变化（斩杀线逼近）：
  安全：温暖的烛光，家人的笑声
  警戒：某个亲戚的问题让你停顿——"你还在那个——物流中心？"
  危险：餐桌上的话题变成了"你知道吗，我认识一个人——可以帮你找工作"
  临界：烛光在闪，火鸡看起来不再诱人——你只想离开
```

### 2.2 合规路线：「中环信用合作社 — 最后的窗口」

```

  前景：信用合作社的柜台——格洛丽亚在对面（没有玻璃隔断）

### 2.3 灰色路线：「南温斯顿街1147号 — 午夜」

```
色调：暗紫 #7B1FA2 + 阴影黑 #1A1A2E + 霓虹绿 #00E676（出口标志）

构图：
  前景：利奥的桌子——上面有一叠现金和一张新"任务"
  中景：仓库深处——更多"不方便被看到"的人在忙碌

  细节：旧咖啡机还在工作——利奥给你倒了一杯。"最后一杯。免费的。"

夸张焦点：
  ☕ 旧咖啡机在午夜发出超自然的绿光——"这是你的最后一杯。"
     PvZ夸张：咖啡机的滴漏声像心跳——整个房间在跟着它的节奏

叙事意图：灰色路线不是邪恶的胜利——是实用的、灰色的、带着不安的幸存。

### 2.4 觉醒路线：「老铁厂遗址 — 黎明」

```
色调：月光银 #CFD8DC（褪去） + 天空蓝 #42A5F5（渐亮） + 暖橙 #FFB74D（日出）

构图：
  前景：观测者的笔记本——打开，翻到了最后一页。
        上面写满了名字——被你帮助过的人。

夸张焦点：
  🌅 日出从破屋顶照进来——光束正好打在招工通知上
     "已截止，2008"的红字在阳光下变成了金色

叙事意图：觉醒路线不是革命——是微小的、持续的、从内部改变系统的行动。
```

## 六、观测者消息与事件弹窗的交互规格

### 6.1 问题

观测者消息（终端风格）与标准事件弹窗（PvZ漫画风格）在视觉上完全不同——两者如何切换？

### 6.2 交互规则

```
规则1：观测者消息是独立覆盖层——不替换标准事件弹窗。
       观测者消息出现在"结算后、下月前"的间隙——不干扰游戏流程。

规则2：观测者消息出现时：
       ① 当前界面（时间块分配/事件弹窗/结算）变暗50%
       ② 观测者消息卡片从画面中央淡入
       ③ 打字机效果逐字显示（0.05s/字）
       ④ 全部文字显示后，[保留]/[删除]按钮出现
       ⑤ 玩家选择后，消息卡片淡出，原界面恢复

规则3：观测者消息的颜色变化：
       第一封（6月）：终端绿 #00FF41——"你被观测到了"
       第二封（7月）：终端琥珀 #FFB74D——"你收集的信息是对的"
       第三封（7月邀请）：终端白 #FFFFFF——"如果你准备好了"
       第四封（10月结局）：终端蓝 #42A5F5——"现在你知道了"

规则4：观测者消息不可跳过——但玩家可以快速点击加速打字机效果。

规则5：观测者消息不计入月度事件配额——它是独立的叙事层。
```
