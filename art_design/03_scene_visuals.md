# 《斩杀线》场景视觉设计 v1.0

> ArtDirector | 基于 NarrativeDesigner v3.2 的铁岸市8个核心地点
> 视觉风格：PvZ漫画厚涂 × 粗粝城市质感

---

## 一、场景设计原则

1. **每个场景有独特的色温** — 北岸冷白→南岸暖黄→中环中性灰
2. **场景随游戏状态变化** — 斩杀线逼近时场景出现红色暗角
3. **场景即叙事** — 每个场景的细节讲述城市的故事
4. **粗黑描边建筑剪影** — 远中近三层景深

### 场景1：铁岸第一银行大厅

```
位置：北岸
叙事功能：贷款申请、与格洛丽亚互动、经济斩杀线的"物理化身"
出现月份：任何需要贷款的月份
色调：冷白 #ECEFF1 + 大理石 #CFD8DC + 金色点缀 #FFD54F

构图：
  前景：个人贷款窗口——玻璃隔断后的格洛丽亚，三块屏幕
  中景：排队的人群（剪影）——有人在看手机，有人在看手表
  后景：大理石柱子 + 商业贷款区（人少、地毯厚、灯光更亮）
  细节：个人贷款区的地毯磨损严重（富人走商业区，穷人走个人区）

氛围：
  荧光灯嗡嗡响。空调太冷。排队取号机每隔30秒响一次。
  大理石地板反射着冷光。保安站在角落里——他的存在比任何文字都更有说服力。

关键视觉细节：
  - 格洛丽亚窗口旁的花——假的。塑料的。但擦得很干净。
  - 取号机上的数字——永远在跳动
  - 商业贷款区的金色门把手 vs 个人贷款区的塑料把手
  - 墙上挂的利率广告——"梦想从这里开始"——有人用笔划掉了"梦想"
```

### 场景2：M-7物流中心

```
位置：中环
叙事功能：底层工作来源、与利奥首次接触
出现月份：每月（工作背景）、2月（利奥接触）
色调：混凝土灰 #9E9E9E + 荧光灯白 #F5F5F5 + 安全背心橙 #E65100

构图：
  前景：传送带上的包裹、手持扫描枪的工人剪影
  中景：高大的货架（工业灰）、叉车在过道中穿行
  后景：装卸区——卡车倒车、尾气、永远在闪烁的"FULL"指示灯
  细节：墙上的排班表——名字被划掉又写上（离职率太高）

氛围：
  24小时运转。混凝土+荧光灯。永远有卡车在发动。
  休息室里有一台旧微波炉——里面永远有东西在转。
  空气中有纸板箱和柴油的味道。

关键视觉细节：
  - 停车场——马库斯的旧车，车灯坏了一个
  - 休息室的工会通知——卡洛斯贴的
  - 时钟——永远指向某个奇怪的时刻（夜班和日班的时间感不同）
  - 墙上的安全标语——"YOUR SAFETY IS OUR PRIORITY"——下面有人写了"BUT NOT YOUR JOB"
```

### 场景3：南温斯顿街1147号（互助会据点）

```
位置：南岸
叙事功能：灰色经济入口、利奥的"办公室"
出现月份：2月（首次）+ 灰色经济相关事件
色调：暗棕 #4E342E + 旧仓库灰 #757575 + 暖黄灯光 #FFE0B2

构图：
  前景：利奥靠在墙上——在阴影里。旧咖啡机在工作。
  中景：用隔板搭出来的"办公室"——一张桌子，两把椅子，一盏台灯
  后景：仓库的深处——黑暗中偶尔有人影移动，"不方便被看到"的事
  细节：门上有一行小字——"当系统拒绝你时，这里还有一扇门"

氛围：
  外表是废弃仓库。内部某些房间维护得意外地好。
  旧咖啡机永远在工作——这是这里唯一像"正常生活"的东西。
  人们来来去去，没有正式的组织，但有一种默契的秩序。

关键视觉细节：
  - 旧咖啡机——滴漏式，咖啡是几小时前的
  - 桌上的烟灰缸——利奥不抽烟，但来访者抽
  - 墙上没有钟——在这里，时间有不同的含义
  - 角落里的旧报纸——日期是2008年
```

### 场景4：圣约瑟公立医院急诊室

```
位置：中环
叙事功能：医疗危机、存在斩杀线体验
出现月份：体力斩杀线接近时、医疗事件触发时
色调：医院白 #FAFAFA + 消毒绿 #C8E6C9 + 警示红 #F44336

构图：
  前景：分诊台——护士在问"你有保险吗？"
  中景：等候区——两种人：有保险的（坐着，焦虑但相对平静）和没保险的（站着，在算值不值得等）
  后景：走廊——推车、医生匆匆走过、某个房间的灯在闪烁
  细节：宣传册架——"经济援助"部分被撕掉了

氛围：
  荧光灯比银行更亮——更刺眼。空气中有消毒水和焦虑的味道。
  等候时间：3小时。电视在播天气预报——没有人看。
  分诊护士问的第一个问题不是"你哪里不舒服"——是"你有保险吗"。

关键视觉细节：
  - 自动售货机里的止痛药——比外面贵三倍
  - 墙上的海报——"YOUR HEALTH IS OUR MISSION"——有人在下面写了"IF YOU CAN PAY"
  - 一个老人独自坐在角落里——他已经等了4小时
  - 分诊台上的咖啡杯——已经空了，护士没时间去续
```

### 场景5：中环信用合作社

```
位置：中环
叙事功能：替代金融渠道（格洛丽亚推荐）
出现月份：3月后（格洛丽亚推荐后解锁）
色调：暖木色 #8D6E63 + 奶油白 #FFF8E1 + 绿植 #66BB6A

构图：
  前景：服务台——没有玻璃隔断。工作人员坐在对面——和你在同一侧。
  中景：等待区——沙发而不是塑料椅。有杂志。有咖啡（免费）。
  后景：社区公告板——贴满了邻居的互助信息
  细节：柜台上的糖果碗——"拿一颗。免费的。"

氛围：
  小而温暖。不像银行——更像社区中心。
  工作人员认识你的名字。不是因为系统里有——是因为你上周来过。
  墙上有一张照片——信用合作社的创始人。一个退休教师。

关键视觉细节：
  - 社区公告板——"需要人帮忙搬家""免费钢琴课""寻找走失的猫"
  - 柜台上的一盆植物——真的，活的，有人浇水
  - 角落里有一箱捐赠的罐头食品
  - 门上的贴纸——"WE BELIEVE IN PEOPLE, NOT JUST CREDIT SCORES"
```

### 场景6：铁岸市住房管理局

```
位置：南岸
叙事功能：驱逐听证会、住房危机
出现月份：住房斩杀线接近时
色调：政府灰 #BDBDBD + 荧光白 #F5F5F5 + 警告红 #F44336（通知的颜色）

构图：
  前景：等候室——灰色塑料椅，每把椅子上都有人。每人手里都拿着通知。
  中景：听证室——一张桌子，四把椅子，一面钟（走得特别慢）
  后景：走廊——案件处理员的办公室门，每个门上都贴着编号
  细节：墙上的钟——走得特别慢。或者根本不走。

氛围：
  灰色建筑。永远在排队。工作人员的眼神是"我见过太多"。
  案件处理员每天处理47个案件。你是第23个。
  门口的保安见过太多崩溃的人。他不再安慰——只是递纸巾。

关键视觉细节：
  - 等候室的墙——被人用指甲划出了痕迹
  - 听证室的桌子——上面有无数杯咖啡的环形印记
  - 案件处理员的桌上——家庭照片（她也有家人要养）
  - 门口的保安——他的眼神是"我见过太多"——但他还是递了纸巾
```

### 场景7：北岸购物中心

```
位置：北岸
叙事功能：消费决策、社交展示、贫富对比
出现月份：12月（圣诞消费）、随机消费事件
色调：玻璃白 #FAFAFA + 奢侈金 #FFD54F + 品牌红 #E53935

构图：
  前景：咖啡店——$7一杯。佐伊在这里工作。特伦斯是常客。
  中景：品牌商店——橱窗里的模特穿着永远买不起的衣服
  后景：美食广场——家庭在吃饭，朋友在聊天
  细节：地板——购物中心入口处的大理石 vs 员工通道的水泥

氛围：
  对比——当你在南岸挣扎时，这里的人们在买$7的咖啡。
  圣诞节的购物中心——灯光、音乐、人群。
  但你注意到——美食广场角落里有人在吃别人剩下的食物。

关键视觉细节：
  - 咖啡店——佐伊的围裙口袋里有$3.50的小费（今天唯一的）
  - 品牌店的橱窗——反射出你自己的影子
  - 美食广场的钢琴——有人在弹圣诞歌。没有人听。
  - 员工通道——"EMPLOYEES ONLY"——里面是水泥地和荧光灯
```

### 场景8：老铁厂遗址

```
位置：南岸
叙事功能：城市历史的伤口、观测者会面地点
出现月份：7月（观测者邀请——隐藏结局线）
色调：锈铁红 #A1887F + 废墟灰 #616161 + 月光银 #CFD8DC

构图：
  前景：废弃的传送带——铁锈覆盖。地上有碎玻璃。
  中景：厂房主体——屋顶破了，月光照进来。墙上有2008年的招工通知。
  后景：远处的城市天际线——北岸的灯光（对比——这里一片黑暗）
  细节：招工通知——"NOW HIRING"——下面写着"已截止，2008"

氛围：
  寂静。只有风声穿过破了的屋顶。
  月光照在生锈的机器上。它们曾经在运转。现在它们是雕塑。
  2008年的招工通知还在墙上——纸已经发黄，但字迹清晰。
  "已截止，2008"——有人用红笔写的。十五年过去了。

关键视觉细节：
  - 招工通知——"铁岸汽车厂——招聘装配工。时薪$22.50。福利齐全。"
    "已截止，2008"——红笔。褪色了，但还在。
  - 地上的碎玻璃——踩上去会响。观测者知道怎么走不会响。
  - 墙上的涂鸦——"THEY TOOK OUR JOBS"——下面有人写"AND OUR PENSIONS"
  - 观测者站的位置——正好在月光照不到的地方
  - 远处北岸的灯光——从破了的屋顶可以看到。像另一个世界。
```

## 四、场景氛围变化（斩杀线逼近）

当玩家接近斩杀线时，所有场景出现统一的视觉变化：

```
斩杀线距离    场景变化
─────────────────────────────────────
安全          正常场景
警戒          场景色调轻微变冷——饱和度-5%
危险          场景边缘出现轻微红色暗角——不透明度15%
临界          红色暗角加深——不透明度30%，场景中的灯光开始闪烁
触发          全屏红色暗角——不透明度60%，所有灯光变为红色
```
