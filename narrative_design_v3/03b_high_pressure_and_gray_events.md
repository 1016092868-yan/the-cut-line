# 《斩杀线》随机事件系统 v3.1 — 高压事件与灰色地带

> 关键优化：打破A/B/C对称模板 + 增加高压对峙事件 + 增加灰色地带事件 + 数据结构示例

## 一、打破模板化：非对称选项事件

原v3.0中大部分事件使用A/B/C三选一模式。以下为打破模板的新事件设计——选项数量不固定，选项间差异在"质"而非"度"。

### E-H01：「催债人的电话」— 高压对峙

```
触发条件：经济斩杀线"危险"或更低
类型：负面高压

叙事：
  电话响了。你接起来。
  "陈先生，我是第一银行的罗德里格斯。
   您的账户已经逾期47天。我们需要讨论还款方案。"
  
  你的手心在出汗。你看着厨房台面上那叠账单。
  最上面那封是红色的。

选项（仅2个，都不好）：
  
  A. "我可以付$200。现在。"
     → 催收员："$200不够覆盖最低还款额。但我可以记录你'正在尝试'。"
     → 效果：- $200，获得2周缓冲期。但催收电话会在2周后再次响起。
     → 叙事："你在拖延。但拖延也是一种策略。"
  
  B. "我需要更多时间。"
     → 催收员："(停顿。打字的声音。) 我可以给你一个'困难延期'——30天。
        但这会记录在你的信用报告上。"
     → 效果：获得30天缓冲期，但信用评分永久-15。
     → 叙事："你买了时间。代价是你的信用。但如果你现在需要的是时间——这是值得的。"

[注意：没有"好的"选项。没有"全额还款"选项——因为玩家没有这个能力。
 这就是斩杀线的本质——你不是在选好的和坏的。你是在选两种坏的方式。]
```

### E-H02：「门上的通知」— 驱逐危机

```
触发条件：住房斩杀线"临界"
类型：高压对峙

叙事：
  你回到家。门上贴着一张纸。
  邻居们在走廊里假装没看到。
  
  "铁岸市住房管理局通知：
   根据……您需在14天内支付逾期租金$2,400
   或腾空该住所。"
  
  14天。$2,400。你没有$2,400。

选项（3个，但路线不同）：

  A. 去住房管理局申诉
     → 效果：- 2天时间，- $50申请费。可能获得额外30天。也可能被拒绝。
     → 不确定性：60%成功 / 40%失败
     → 叙事："你坐在等候室里。你前面有12个人。他们的手里都拿着同样的通知。"
  
  B. 向玛格丽特求助（需要已建立社区连接）
     → 效果：玛格丽特认识一个人——她的前同事的侄子有一个空房间。不是公寓。是一个房间。
     → 叙事："'这不是长期的，'玛格丽特说。'但至少你不会在街上。'"
     → 条件：前置事件E-P02或E-P02-C已完成
  
  C. 向南岸互助会求助（需要已接触利奥）
     → 效果：利奥可以借你$2,400。但利息是——他不说"利息"。他说"以后我需要你帮一个忙"。
     → 叙事："利奥没有笑。他从来不笑。但他点头了。你欠他一个人情。你不知道这个人情值多少。"
     → 条件：前置事件"利奥的第一次接触"已完成

[注意：选项B和C需要前置条件——不是所有人都能选。
 这强化了"之前的选择决定现在的选项"的叙事原则。]
```

### E-H03：「急诊室的夜晚」— 体力斩杀线逼近

```
触发条件：体力斩杀线"危险"或更低 + 有子女角色概率翻倍
类型：高压

叙事：
  凌晨3点。你的孩子/你自己——高烧40度。
  你去了急诊室。分诊护士问的第一个问题是：
  "你有保险吗？"
  
  你犹豫的那一秒——她已经知道了答案。

选项（2个 + 1个隐藏）：

  A. "有。"（撒谎——你没有。或者你的保险被暂停了。）
     → 效果：得到治疗。但一个月后你会收到账单——$3,800。
     → 叙事："你签了字。你知道你签的是什么。但孩子在发烧。"
  
  B. "没有。"
     → 效果：仍然得到治疗（法律规定急诊室不能拒绝）。但你会被引导到"慈善护理"流程——
        一叠需要填写的表格，一个"可能减免"的承诺，和一个漫长的等待。
     → 叙事："护士的表情没有变化。她见过太多。但她的打字速度慢了——她在给你更多时间。"
  
  [隐藏选项——仅在社区连接≥2时出现]
  C. "我有社区信用合作社的紧急医疗基金。"
     → 效果：- $500，得到治疗，无后续账单。
     → 叙事："格洛丽亚告诉你的那个信用合作社——你去了。他们有一个'社区紧急基金'。不多。但够。"
```

## 二、灰色地带事件：没有明确好坏的选择

### E-G01：「钱包」— 道德灰色

```
触发条件：随机，低概率
类型：灰色地带

叙事：
  你在超市停车场发现了一个钱包。里面有$340现金。
  还有一张身份证——一个老人。地址在南岸。
  
  你站着。钱包在你手里。
  $340。差不多是你一周的工资。
  那个老人——可能也需要这笔钱。也可能不需要。

选项（3个，没有一个是"正确的"）：
  
  A. 归还钱包，保留现金
     → 你寄回了身份证和信用卡。但留下了$340。
     → 叙事："你告诉自己——他可能不会注意到。或者——这是他应该付的'找回费'。你几乎相信了。"
     → 效果：+$340，-自尊，小概率触发后续事件（老人联系你——他没有生气，只是问"为什么"）
  
  B. 全部归还
     → 你寄回了所有东西。包括$340。
     → 叙事："你在邮局排队。$340在你口袋里很重。但你把它放进了信封。"
     → 效果：+自尊，+社区声望（老人告诉了邻居）。一周后，你的门口出现了一袋橙子。没有署名。
  
  C. 全部保留
     → 你把钱包扔进了垃圾桶。$340在你的口袋里。
     → 叙事："你告诉自己——我需要这个。比那个老人更需要。你不知道这是不是真的。"
     → 效果：+$340，-自尊（大幅），小概率触发后续事件（老人的家人通过摄像头找到了你）
```

### E-G02：「同事的过错」— 职场灰色

```
触发条件：在Corporate跑道的角色
类型：灰色地带

叙事：
  你的同事杰西卡犯了一个错误——一个$5,000的错误。
  你看到了。你可以在它被上报之前修正它。
  但如果你修正了——杰西卡会欠你一个人情。如果你不修正——
  杰西卡可能被开除。而她的职位——你可以申请。

选项：
  
  A. 修正错误，告诉杰西卡
     → 效果：+社交（杰西卡欠你），-时间，无即时经济影响
     → 叙事："她看着你——'为什么？'你耸了耸肩。'下次你看到我的错误——你也修正它。'"
  
  B. 修正错误，不告诉任何人
     → 效果：无即时影响。但杰西卡不知道。
     → 叙事："你修正了错误。没有人知道。包括杰西卡。你在想——这是善良还是懦弱？"
  
  C. 不修正。让系统运行。
     → 效果：杰西卡可能被开除（70%概率）。如果她被开除——你可以申请她的职位。
     → 叙事："你什么都没做。第二天——杰西卡被叫进了HR办公室。你看着。你的手没有抖。这是最可怕的。"
```

## 四、优化后的事件质量自检清单

每个事件在定稿前必须通过：

- [ ] 是否至少有一个选项让玩家真正犹豫？
- [ ] 选项之间是否在"质"上不同（不同的价值观/代价/策略路线）？
- [ ] 是否存在前置条件锁定的选项——反映"之前的选择决定现在的选项"？
- [ ] 是否有延迟后果——而非全部即时结算？
- [ ] 叙事文本是否传达了情感重量——而非只是描述效果？
- [ ] 是否有角色特定的叙事变体（至少为主要角色）？
- [ ] 事件是否避免了A/B/C的对称模板——如果对称，是否有充分理由？
