# 《斩杀线》随机事件系统 v3.0

> 事件是叙事的引擎。每一个随机事件都是一扇"如果……会怎样"的窗。
> 设计原则：事件不是随机惩罚——是叙事机会。

---

## 一、事件系统设计理念

### 核心原则

1. **事件不是凭空出现**：好的事件是之前决策的自然延伸，坏的事件是系统压力的具象化
2. **事件有沉默期**：不是每个决策都立刻有后果——有些需要等待，在玩家几乎忘记时才浮现
3. **事件有错过窗口**：某些机会只在特定时间段出现，错过就是永远
4. **事件反映角色**：同一个事件，不同角色会看到不同的选项和结果
5. **事件链**：某些事件是链条的一部分——一个选择触发下一个事件

### 事件触发机制

```
全局事件池（每月1-2次）
    ├── 基于角色身份的专属事件（每2-3月1次）
    ├── 基于斩杀线维度的压力事件（接近斩杀线时触发）
    ├── 基于之前选择的后果事件（延迟触发，1-3个月后）
    ├── 基于时间节点的季节事件（感恩节/圣诞/报税季等）
    └── 纯随机事件（低概率，高影响）
```

## 二、全局事件池

### 正面事件（30%概率）

#### E-P01：「意外之财」
```
你收到一笔意外的钱——退税、旧押金退还、忘记的储蓄账户。
金额：$200-$800

叙事："一封信。一张支票。你盯着数字看了很久。
       这种好事多久没发生过了？"

选择：
  A. 立即存入储蓄 → +资金，无副作用
  B. 投资于一个小机会 → 高风险，可能翻倍或归零
  C. 用于"正常生活"的体验 → +短期心情，可能引发后续消费压力
```

#### E-P02：「陌生人的善意」
```
一个陌生人（或半陌生人）提供意外的帮助。
触发条件：社会斩杀线接近时概率提高。

叙事："玛格丽特老太太敲了你的门，手里端着一锅汤。
       '多做了一份。不是可怜你。就是做多了。'"

选择：
  A. 接受帮助 → +食物 +心情 +社区连接
  B. 婉拒但保持联系 → +自尊但错过实际帮助
  C. 接受并开始定期互助 → 解锁社区互助网络
```

#### E-P03：「技能变现」
```
有人需要你恰好拥有的技能，愿意付钱。
触发条件：有特定技能时概率提高。

叙事："一个邻居在社区群里问：'有人会修热水器吗？急。付现金。'"

选择：
  A. 接下这份活 → +现金 +社区声望
  B. 推荐别人 → +关系但错过收入
  C. 报价更高 → 可能获得更多，也可能失去机会
```

#### E-P04：「信息优势」
```
利奥传来一个"内部消息"——某个机会窗口即将关闭或打开。
触发条件：灰色网络连接存在时。

叙事："'有个东西你可能想知道，'利奥的声音在电话里永远是平的，
       '要不要听，你自己决定。'"

选择：
  A. 获取信息并行动 → 解锁隐藏机会
  B. 获取信息但不行动 → 信息存为知识，可能未来有用
  C. 拒绝获取 → 保持距离但可能错过关键机会
```

#### E-P05：「临时的避难所」
```
有人提供一个临时的、便宜的住处。
触发条件：住房压力高时。

叙事："'我有个储藏室，不大，但有暖气。如果你需要过渡一下……'
       对方没有说完。"

选择：
  A. 接受 → 住房成本大幅降低，但生活质量和自尊受损
  B. 拒绝 → 保持尊严但经济压力持续
```

#### E-P06：「意外的贵人」
```
一个你不认识的人给了你一个机会——不是施舍，是认可。
触发条件：低概率随机。

叙事："'我看了你的作品/简历/工作。'对方说。
       '我这里有一个位置。不一定更好。但是一个开始。'"

选择：
  A. 抓住机会 → 新收入渠道或职业转变
  B. 谨慎观望 → 保留当前状态但可能错过窗口
```

#### E-P07：「社区的回报」
```
当你最需要时，社区出现了。
前置条件：之前帮助过社区/邻居。

叙事："你门口放着一个信封。里面是几张皱巴巴的钞票。
       一张纸条：'上次你帮了我。这次轮到我了。'没有署名。"

效果：+$500-$2,000 + 社区信任永久+1
```

### 负面事件（40%概率）

#### E-N01：「账单总是准时」
```
一笔预期外的账单——医疗、维修、罚款。
金额：$150-$1,200

叙事："信封上的标志你认识。你不需要打开就知道里面是什么。
       但你还是打开了。"

选择：
  A. 立即支付 → -资金，无后续影响
  B. 延期支付 → 资金压力推迟，但开始累积利息和催款
  C. 忽略 → 信用受损，可能触发连锁后果
```

#### E-N02：「你被看见了」
```
有人注意到了你的灰色活动——可能是执法者，也可能是竞争者。
触发条件：灰色路线活跃时。

叙事："一辆车停在你门口的时间比平常长了三秒。
       没有人下来。然后它开走了。"

选择：
  A. 暂停灰色活动 → 收入中断但降低风险
  B. 继续但更小心 → 收入减半，风险不变
  C. 无视 → 高风险，可能触发执法事件
```

#### E-N03：「关系的裂痕」
```
一个重要关系出现紧张——争吵、沉默、或背叛。
触发条件：社会压力高时。

叙事（以马库斯为例）：
"艾玛在电话里说：'你答应过这周末来接我的。'
 你的心沉了下去。你完全忘了。"

选择：
  A. 尽力弥补 → -时间 -资源，+可能修复关系
  B. 诚实解释 → +可能理解，也可能失望
  C. 找借口 → 短期避免冲突，长期损害信任
```

#### E-N04：「系统的信」
```
收到来自系统的正式通知——驱逐、起诉、取消资格。
触发条件：接近斩杀线时。

叙事："这封信的措辞很礼貌。非常礼貌。礼貌到让你想吐。"

选择：
  A. 走正式申诉流程 → -时间，结果不确定
  B. 寻求法律/社区帮助 → 可能获得延期或减免
  C. 接受 → 斩杀线加速逼近
```

#### E-N05：「健康不会等待」
```
健康问题——牙痛、感染、旧伤复发。
触发条件：随机（年龄大的角色概率更高）。

叙事："你醒来时，身体告诉你一个你不想听的消息：
       有些事情不对。"

选择：
  A. 去看医生 → -大量资金，但问题解决
  B. 自己处理 → -少量资金，但可能恶化
  C. 忍着 → 无即时成本，但健康值持续下降
```

#### E-N06：「被替代」
```
你的工作/收入来源被替代——新人、新技术、新规则。
触发条件：工作中后期。

叙事："'这不是针对你个人。'他们说。他们总是这么说。"

选择：
  A. 接受并寻找新机会 → 开启新收入渠道的搜索
  B. 争取保留位置 → 可能成功但消耗社会资本
  C. 升级技能 → -时间 -资金，但长期回报
```

#### E-N07：「意外的访客」
```
一个你不想见的人出现在门口——债主、前伴侣的律师、移民官。
触发条件：特定斩杀线维度接近时。

叙事："敲门声。三下。你从猫眼看了一眼。
       你希望你不认识那个人。但你认识。"

选择：
  A. 开门面对 → 可能加剧危机，但至少你在掌控
  B. 假装不在 → 暂时躲过，但问题不会消失
  C. 从后窗离开 → 逃避，但可能引发更严重的后果
```

### 中性事件（30%概率）

#### E-NU01：「旧日回响」
```
过去生活的痕迹出现——一张旧照片、一个老朋友的消息。

叙事："你在超市里看到了一个人。他/她也看到了你。
       你们对视了一秒，然后都移开了目光。"

选择：
  A. 主动打招呼 → 可能重新连接，也可能被拒绝
  B. 假装没看见 → 安全但孤独
```

#### E-NU02：「微小的选择」
```
一个与生存无关的微小选择——但揭示角色的价值观。

叙事："排队时，前面的人掉了一张二十美元的钞票。
       没有人注意到。你注意到了。"

选择：
  A. 归还 → +自尊，可能+社会声望
  B. 拿走 → +$20，-自尊
  C. 假装没看见 → 保持中性
```

#### E-NU03：「窗外的世界」
```
一个纯粹的"观察"时刻——街头演奏者、夕阳、孩子的笑声。

叙事："你停下脚步。不是因为你必须停下。
       只是因为有一瞬间，你记得世界还在转动。"

选择：
  A. 停下来享受这一刻 → +心情值，-时间
  B. 继续赶路 → 效率优先
```

#### E-NU04：「深夜来电」
```
凌晨两点，电话响了。是一个很久没联系的人。

叙事："屏幕上的名字让你愣了一秒。
       你已经三年没见过这个名字了。"

选择：
  A. 接听 → 可能是一个机会，也可能是一个负担
  B. 不接 → 保持平静，但永远不知道错过了什么
```

#### E-NU05：「镜中人」
```
你在镜子里看到了自己。不是匆匆一瞥——是真正的对视。

叙事："你有多久没有认真看自己了？
       镜子里的人看起来——有点陌生。"

效果：无即时影响。触发角色独白反思。
     可能影响后续决策的倾向。
```

## 三、因果事件链

事件不是孤立的。以下是几条核心事件链：

### 链1：灰色经济的代价

```
E-N02 "你被看见了"（警告）
    ↓ 如果玩家无视
E-N02-B "第二次警告"（更明确——同一辆车，这次停了更久）
    ↓ 如果继续无视
E-N02-C "敲门的不是朋友"（执法/竞争者上门）
    ↓
后果：灰色收入渠道关闭 + 社会斩杀线大幅逼近 + 可能的法律后果
```

### 链2：社区互助的回报

```
E-P02 "陌生人的善意"（玛格丽特的汤）
    ↓ 如果接受并建立互助关系
E-P02-B "社区的呼唤"（有人需要你的帮助）
    ↓ 如果提供帮助
E-P02-C "当你也需要时"（社区在你最困难时出现）
    ↓
结果：解锁"社区安全网"——在斩杀线最接近时获得缓冲
```

### 链3：关系的瓦解（或修复）

```
E-N03 "关系的裂痕"（争吵/遗忘/背叛）
    ↓
    ├── 选择弥补 → E-N03-B "修复的尝试"（可能成功/可能失败）
    │       ↓
    │       ├── 成功 → 关系强化，解锁"深层信任"
    │       └── 失败 → 关系进一步恶化
    │
    └── 选择回避 → E-N03-C "沉默的代价"（关系自然消亡）
            ↓
            后果：永久失去该关系带来的社会资本
```

### 链4：系统的警告

```
E-N04 "系统的信"（第一封——白色）
    ↓ 如果忽略
E-N04-B "第二封信"（黄色——语气更严厉）
    ↓ 如果继续忽略
E-N04-C "最后一封"（红色——强制执行）
    ↓
后果：对应的斩杀线维度触发
```

## 四、季节事件（固定时间触发）

### 11月 感恩节
```
"感恩节晚餐"
叙事："你被邀请（或不被邀请）参加感恩节晚餐。
       这是美国最大的社交考验。"

触发角色差异：
  马库斯：前妻邀请他一起过节——"为了艾玛"。他需要决定。
  佐伊：回家面对父母的"工作怎么样了"。
  安娜：第一次被邻居邀请参加感恩节——她不知道该带什么。
  特伦斯：父亲的年度"进展汇报"。

选择：
  A. 参加 → +社交但可能+情感压力
  B. 婉拒 → 保持平静但可能伤害关系
  C. 自己过 → 孤独但自由
```

### 12月 圣诞节
```
"圣诞消费压力"
叙事："礼物清单在你面前。你算了一下总价。
       然后你闭上了眼睛。"

选择：
  A. 尽力满足所有人 → -大量资金 +社交
  B. 坦诚预算有限 → 可能理解，可能失望
  C. 跳过礼物 → -社交但保护资金
```

### 4月 报税季
```
"报税日"
叙事："你坐在桌前，面前是一堆表格。
       可能是退税——也可能是补税。"

随机结果：
  退税（60%概率）：+$500-$3,000
  补税（30%概率）：-$200-$1,500
  审计（10%概率）：需要更多文件——+压力，结果延迟
```

### 6月 毕业季（仅对年轻角色/有孩角色）
```
"毕业典礼" / "学贷开始还款"
触发：角色年龄≤25或有子女≥18岁

叙事（以佐伊为例）：
"毕业一年了。学贷的宽限期结束了。
 第一笔还款从你的账户里扣除。
 $920。每个月。从现在开始。"
```

## 五、角色专属事件池（每角色5-8个）

已在角色系统中详细列出。此处补充角色专属事件的通用触发规则：

### 专属事件触发条件

| 触发类型 | 条件 | 示例 |
|----------|------|------|
| **时间触发** | 游戏进行到特定月份 | "艾玛的生日"（马库斯专属，3月） |
| **状态触发** | 某维度接近斩杀线 | "前妻的律师信"（马库斯专属，社交斩杀线接近） |
| **关系触发** | 与特定NPC的关系达到阈值 | "玛丽亚的加班"（卡洛斯专属，婚姻关系紧张） |
| **选择触发** | 之前的某个选择解锁 | "投资人的电话"（伊桑专属，之前选择了"发送商业计划"） |
| **随机触发** | 低概率随机 | "旧伤复发"（德里克专属，5%概率/月） |

## 六、事件叙事质量标准

每个事件在定稿前必须通过以下检查：

- [ ] 事件的描述是否让玩家在0.5秒内理解"发生了什么"？
- [ ] 选择是否在"质"上不同——不同的价值观、代价、策略？
- [ ] 是否存在至少一个选项让玩家犹豫？
- [ ] 事件是否有延迟后果——而非即时结算？
- [ ] 事件是否与角色的身份/背景产生共鸣？
- [ ] 是否有至少一行叙事文本让玩家感受到情感重量？
- [ ] 在第三遍阅读时，有没有可以删掉而不影响意义的词？

## 七、事件密度控制

| 游戏阶段 | 月事件数 | 正面% | 负面% | 中性% | 说明 |
|----------|:------:|:-----:|:-----:|:-----:|------|
| 初期（第1-3月） | 2-3 | 15% | 55% | 30% | 快速建立压力 |
| 中期（第4-7月） | 3-4 | 30% | 35% | 35% | 机会与压力并存 |
| 后期（第8-11月） | 4-5 | 25% | 45% | 30% | 高压，最终抉择 |
| 终局（第12月） | 2-3 | 根据结局 | 根据结局 | - | 叙事收束 |
