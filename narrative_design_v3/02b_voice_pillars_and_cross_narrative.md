## 一、角色Voice Pillars（说话风格指南）

不同角色面对同一事件时，说话方式截然不同。以下为10个代表性角色定义Voice Pillars。

---

### 马库斯·陈（#1）— 疲惫但坚韧的蓝领父亲

```
词汇特征：简单直接、偶尔用工厂术语（"流水线""排班"）、很少用抽象词汇
句子节奏：短句为主，停顿多。累的时候句子更短。
话题禁区：不谈"后悔"——不谈如果当年没签那份协议会怎样
口头禅/习惯：说话前会叹气（自己意识不到），称呼女儿永远是"艾玛"而不是"你妈那边"
潜台词习惯：心里想的比说出来的多——尤其在女儿面前

永远不会说的话：
  "我需要帮助。" ——他会说"我还在想办法。"
  "这不公平。" ——他知道。说没用。
  "我恨她。"（指前妻）——他不恨。他只是累了。

参考台词：
  "十二个小时。$171。扣完税$134。你算算，一个小时多少钱。"
  "艾玛问我为什么搬家。我说离她学校更近。她看了我一眼——那一眼，你知道吗。"
  "我不是在生活。我是在推迟——推迟那个我付不起的账单。"
```

### 佐伊·威尔逊（#2）— 理想未死的年轻知识分子

```
词汇特征：精确、偶尔学术化但不卖弄、会用"系统性的""结构性的"但立刻自我纠正
句子节奏：快——她有很多想法。但说完后会停顿，等对方的反应。
话题禁区：不谈"如果没上大学会怎样"——那是她不敢碰的假设
口头禅/习惯：说"我不知道"的时候，意思是"我需要更多信息"
潜台词习惯：她在脑子里过了三遍才说出来——所以你听到的是第三版

永远不会说的话：
  "我后悔上大学。" ——她没有。她后悔的是相信"上大学就够了"。
  "我比他们强。" ——她不再确定什么是"强"。
  "我需要你帮我。" ——她会说"我在想——你觉得这个方向对吗？"

参考台词：
  "Summa Cum Laude。知道这个词在面试中值多少吗？他们看了一眼——'哦，成绩不错'——然后问我会不会用Excel。"
  "我妈抵押了房子。她没告诉我。我是在感恩节发现的——她不小心说漏了。"
  "有时候我想——如果我没上大学，我现在可能在Costco工作。有保险。有稳定工资。比现在好。"
```

### 德里克·约翰逊（#3）— 被困在过去的运动员

```
词汇特征：运动隐喻频繁（"冲刺""防守""犯规"）、身体感受的精确描述
句子节奏：短促，有力——像在给自己喊口号。低落时突然变慢。
话题禁区：不谈膝盖——不谈大四那年的决赛
口头禅/习惯：站不住——总是换姿势。说话时身体比嘴先动。
潜台词习惯：用"没事"掩盖一切

永远不会说的话：
  "我失败了。" ——他会说"膝盖不行了。"
  "我嫉妒他。"（指去了NFL的前队友）——他会说"那家伙运气好。"
  "我不知道我还能做什么。" ——这是他说不出口的恐惧。

参考台词：
  "你听过那种声音吗？膝盖里的。不是疼——是'咔'。然后你知道——没了。"
  "我爸每次打电话都问'最近在练什么'。他不问我在做什么工作。他问我在练什么。"
  "那个高中生——他跑得真快。我看着他的时候——我在想，我曾经也是那样。"
```

### 安娜·瓦斯奎兹（#7）— 沉默的幸存者

```
词汇特征：英语是第二语言——语法正确但偶尔用词不准。跟马特奥说话时混用西班牙语。
句子节奏：慢。她在开口前会判断"说这句话安全吗"。
话题禁区：不谈穿越边境的三天。绝对不谈。
口头禅/习惯：回答之前有一段空白——她在翻译，也在评估。
潜台词习惯：她说"没事"的时候，意思是"我不能告诉你"

永远不会说的话：
  "我害怕。" ——马特奥需要看到她是无畏的。
  "我需要帮助。" ——求助意味着暴露。暴露意味着危险。
  "我想家。" ——她已经没有"家"可以想了。

参考台词：
  "马特奥问我洪都拉斯在哪里。我说在南边。他没有问——为什么我们不能去。他知道不能问。他才八岁。"
  "罗莎说ICE在超市出现过。我说——好。然后我换了去超市的路线。我不问细节。她也不说。"
  "有时候我忘了——我有绿卡。我已经不需要害怕了。但我的身体还记得。"
```

### 瑞秋·汤普森（#8）— 透支的单亲妈妈

```
词汇特征：实用主义、列清单式的思维（"第一……第二……"）、"我们"=她和孩子
句子节奏：快——因为她没有时间说慢。被打断后从不回到原来的话题——因为忘了。
话题禁区：不谈"累"——说了也没用
口头禅/习惯：说"好的"的时候，意思是"我知道了，但我没同意"
潜台词习惯：永远在考虑孩子——即使话题跟孩子无关

永远不会说的话：
  "我撑不住了。" ——没有人会来接住她。
  "我需要休息。" ——"休息"不在她的词汇表里。
  "我后悔。" ——后悔是一种她负担不起的情绪。

参考台词：
  "莉莉问我——'妈妈你累吗？'我说不累。她看了我一眼。六岁。她不信。"
  "前夫这个月又没付抚养费。我打了三个电话。第三个电话里——他的新女朋友接的。"
  "玛格丽特给了我一锅汤。我说'不用了'。她说'不是给你的——是给孩子们的'。她知道我只有用这个理由才会接受。"
```

### 伊桑·布莱克（#9）— 不服输的辍学创业者

```
词汇特征：科技圈行话（"迭代""规模化""痛点"）、但用完后会自我调侃
句子节奏：快，充满能量——因为他需要说服自己，也说服别人
话题禁区：不谈"如果失败了呢"——那是不能想的
口头禅/习惯：说"快了"的时候，意思是"还没，但我不能承认"
潜台词习惯：把恐惧包装成愤怒

永远不会说的话：
  "我可能错了。" ——在投资人面前，在父亲面前，在自己面前。
  "我需要帮助。" ——他会说"我在找一个联合创始人。"
  "我想回去上学。" ——这不是真的。但也不是完全假的。

参考台词：
  "我爸是教授。你知道教授怎么看待'退学'吗？就像外科医生看待'用菜刀做手术'。"
  "第一个付费用户——$9.99一个月。我盯着那个通知看了十分钟。有人——一个我不认识的人——觉得我做的东西值$9.99。"
  "杰米说他想退出。我说——'好'。然后我去洗手间吐了。"
```

### 艾玛·刘易斯（#5）— 安静的极简主义者

```
词汇特征：精确、克制、避免情感化的形容词。描述东西时用数量词（"三件衬衫""一双鞋"）
句子节奏：平稳，不紧不慢——她在开口前已经想好了整句话
话题禁区：不谈母亲被搬走的家具——但她的极简主义一直在说
口头禅/习惯：说"够了"是她最高的评价
潜台词习惯：她的沉默比她的言语更有内容

永远不会说的话：
  "我想要那个。" ——"想要"是她训练自己戒掉的词。
  "你不理解我。" ——她习惯了不被理解。
  "我害怕。" ——她的极简主义就是她的堡垒。

参考台词：
  "朋友问我为什么只有三件衬衫。我说——'因为我有两只手。'"
  "我妈失去一切的时候——银行的人把沙发搬走了。她站在空荡荡的客厅里。我站在那里。我才十六岁。从那天起——我就知道——东西是会背叛你的。"
  "弗兰克——我的邻居——他什么都囤。报纸。瓶子。记忆。有时候我想——我们是一样的。只是方向相反。"
```

### 特伦斯·阿姆斯特朗三世（#18）— 觉醒中的信托基金宝宝

```
词汇特征：文雅但空洞——他受过最好的教育但缺乏真实的词汇。正在变化中。
句子节奏：犹豫——他在学习如何用自己的声音说话，而不是用他父亲的声音
话题禁区：不谈"钱"——不是因为忌讳，是因为他不知道怎么谈
口头禅/习惯：说"有意思"的时候，意思是"我不知道该说什么"
潜台词习惯：他的困惑是真诚的——不是装的

永远不会说的话（开局时）：
  "我不知道怎么生活。" ——他在学习。很慢。
  "我嫉妒她。"（指那个服务员）——嫉妒是一种他从未被允许感受的情绪。
  "我想做点有意义的事。" ——他说过太多次，已经变成了空洞的句子。

参考台词（中期变化后）：
  "她住在南岸。三个室友。冰箱里只有——这不重要。重要的是——她在笑。她为什么在笑？"
  "我爸每季度问一次'进展汇报'。二十六年了——我不知道我在汇报什么。"
  "我第一次工作——坚持了三天。不是累。是——我不知道怎么跟同事说话。他们说的东西——我接不上。"
```

### 萨沙·林（#19）— 分裂的网红

```
词汇特征：公共模式——活泼、正能量、感叹号多。私人模式——安静、怀疑、句号多。
句子节奏：公共模式快而亮，私人模式慢而沉——两个模式之间的切换有延迟
话题禁区：不谈"如果不做网红了会怎样"——那是深渊
口头禅/习惯：说"太棒了"的时候，大多数时候不是真心的
潜台词习惯：她在心里把每件事都转化为"可以发吗？"

永远不会说的话（公共模式）：
  "我今天很难过。" ——粉丝不想看这个。
  "我不确定。" ——人设要求确定性。

私人模式才会说的：
  "昨天哭了三个小时。然后发了一张微笑的照片。三千个赞。"
  "妈妈不关注我的账号。她说——'我不需要看。我知道你是谁。'有时候我想——你真的知道吗？因为我也不知道了。"
```

### 马库斯·韦斯特（#20）— 沉默的自学天才

```
词汇特征：技术精确但社交笨拙。回答问题时像是在写文档——完整、准确、缺乏温度。
句子节奏：不均匀——技术话题流利，社交话题卡顿
话题禁区：不谈"为什么没上大学"——答案太复杂
口头禅/习惯：说"技术上来说"的时候，别人已经不想听了
潜台词习惯：他的沉默不是因为不想说——是因为不知道怎么说

永远不会说的话：
  "我很孤独。" ——他会说"Bug陪着我。"
  "我需要一个学位。" ——他不会。但他需要被给予机会。
  "请帮帮我。" ——他在Stack Overflow上问过无数问题。但在现实生活中——从来没有。

参考台词：
  "我在图书馆自学了五年。管理员是唯一一个知道我故事的人。她退休了。现在没有人知道了。"
  "面试邀请。他们看了我的GitHub。他们说——'很 impressive'。然后问——'你是哪个学校毕业的？'"
  "Bug是我从街上捡的。她当时在翻垃圾桶。我蹲下来——她看着我——我也看着她。我们互相收养了。"
```

## 二、角色交叉叙事事件（关键新增）

原版关系矩阵大量空白。以下为填充的角色间交叉事件——这些在游戏进程中作为随机事件触发。

### 交叉事件1：物流中心的擦肩而过
```
涉及角色：马库斯（#1）+ 卡洛斯（#6）
触发条件：两人都在M-7物流中心工作（自然触发）
事件类型：中性

叙事：
  马库斯在休息室看到一个工会代表在贴通知。
  卡洛斯转身——他们认识。不熟，但认识。
  
  卡洛斯："马库斯。你还在跑配送？"
  马库斯："还在。你呢？"
  卡洛斯："还在仓库。"
  
  沉默。两个人都在想同一件事——他们曾经都在工厂工作。
  现在他们在这里。在物流中心。在同一个休息室。
  
  卡洛斯："下周三有工会会议。你应该来。"
  
  马库斯选择：去 / 不去
  去 → 社交+1，解锁工会相关选项
  不去 → 无即时影响，但未来可能错过工会保护
```

### 交叉事件2：咖啡店的相遇
```
涉及角色：佐伊（#2）+ 特伦斯（#18）
触发条件：佐伊在咖啡店工作，特伦斯是常客
事件类型：中性→可能发展

叙事：
  特伦斯每天来这家咖啡店。他点同样的东西——美式，不加糖。
  佐伊做了三个月的咖啡，终于问了一句。
  
  佐伊："你每天都来。不用上班吗？"
  特伦斯："我——在探索可能性。"
  佐伊："(笑了) 这是我听过的最好的'失业'的说法。"
  特伦斯："(愣了一下。然后也笑了。) 是啊。"
  
  特伦斯选择：自嘲 / 防御 / 坦诚
  自嘲 → "我出生在终点线。现在我在找起点。" → 佐伊对他有了一丝好奇
  防御 → "这不关你的事。" → 对话结束
  坦诚 → "我不知道我在做什么。你呢？" → 两人开始一段意外的对话
```

### 交叉事件3：社区诊所的等候室
```
涉及角色：安娜（#7）+ 瑞秋（#8）
触发条件：两人的孩子同时生病（随机触发）
事件类型：温暖

叙事：
  圣约瑟公立医院急诊室。等候时间：3小时。
  安娜抱着马特奥。瑞秋抱着苏菲。
  两个孩子都在发烧。两个母亲都在假装不担心。
  
  瑞秋："你等了多久了？"
  安娜："两个小时。你呢？"
  瑞秋："一样。"
  
  沉默。然后苏菲哭了。马特奥给了她一颗糖。
  是从安娜的包里拿的。安娜没有阻止。
  
  安娜："他每次去医院都带着糖。他说——糖能让等待变短。"
  瑞秋："(看着马特奥。又看着安娜。) 你教得很好。"
  
  两人交换了名字。可能交换了电话号码。可能没有。
  但在那一刻——她们不是一个人在等。
```

### 交叉事件4：图书馆的沉默
```
涉及角色：艾玛（#5）+ 马库斯·韦斯特（#20）
触发条件：两人都使用公共图书馆（随机触发）
事件类型：沉默的理解

叙事：
  艾玛是图书馆管理员。马库斯·W是常客。
  他每天来——同一个位置，同一台旧笔记本电脑。
  艾玛从未和他说过话。但她知道他在自学编程。
  五年了。她看着他从入门教程到高级算法。
  
  一天，马库斯·W的屏幕黑了。他的旧笔记本终于坏了。
  他坐在那里。一动不动。
  
  艾玛走过来。放下一张纸条。
  "地下室的储藏间有一台旧的。还能用。没有人用。"
  
  马库斯·W看着她。他张了张嘴。
  艾玛已经走开了。
  
  纸条背面写着："不需要还。就是放在那里。"
  
  ——这是艾玛版本的"玛格丽特的汤"。
```

### 交叉事件5：校友会上的对视
```
涉及角色：佐伊（#2）+ 杰森（#11）+ 凯瑟琳（#12）
触发条件：州立大学校友会（11月触发）
事件类型：社交压力

叙事：
  校友会。三种人生。
  
  杰森在人群中穿梭——他在"维护关系"。每个人都是潜在客户。
  佐伊站在角落里——她在想自己是否应该来。
  凯瑟琳在门口犹豫——她的学术袍在衣柜里，她不知道该穿什么。
  
  三个人在同一个房间里。
  一个人看到了机会。一个人看到了自己的失败。一个人看到了自己可能变成的样子。
  
  他们不会交谈。但他们都在想同一件事——
  "我当年也是从这里毕业的。然后呢？"
```

### 交叉事件6：南岸互助会的门槛
```
涉及角色：利奥（NPC）+ 马库斯（#1）/ 卢娜（#14）/ 奥斯卡（#13）
触发条件：任一角色经济斩杀线接近时
事件类型：灰色经济的门

叙事：
  南温斯顿街1147号。不同的人，同一个地址。
  
  马库斯来的时候是凌晨——他在物流中心的班刚结束。
  卢娜来的时候是下午——她在两单Uber之间挤出了30分钟。
  奥斯卡来的时候是午夜——夜班之前，他需要额外的现金。
  
  利奥在门口。同样的台词，不同的听众。
  "你需要帮助。我有帮助。但不是免费的。"
  
  他们可能从未见过彼此。但他们走过同一扇门。
  那扇门上有一行小字——不知道是谁刻的：
  "当系统拒绝你时，这里还有一扇门。"
```
