## 一、事件ID命名规范

```
格式：E-{类别}-{序号}-{变体}

类别代码：
  P  = 正面事件 (Positive)
  N  = 负面事件 (Negative)
  NU = 中性事件 (Neutral)
  H  = 高压事件 (High Pressure)
  G  = 灰色地带 (Gray)
  S  = 季节事件 (Seasonal)
  CH = 角色专属事件 (Character-specific)
  CR = 交叉叙事事件 (Cross-narrative)
  OB = 观测者事件 (Observer)

变体代码：
  _B = 因果链第二环
  _C = 因果链第三环
  _ESC = 升级版 (Escalation)
  _REC = 恢复版 (Recovery)
  _ALT = 替代版 (Alternate)

示例：
  E-N01     = 第一号负面事件「账单总是准时」
  E-N04_B   = 「系统的信」因果链第二环（黄色信件）
  E-N04_C   = 「系统的信」因果链第三环（红色信件）
  E-CH01-01 = 角色#1的第1个专属事件
  E-CR03    = 第三号交叉叙事事件
```

## 四、开发者快速接入指南

### 4.1 文件读取顺序

```
1. README.md              → 总体概览
2. 01_world_bible.md      → 世界观、斩杀线定义、情感曲线、多周目差异
3. 02_character_system.md → 20角色完整档案（叙事内容）
4. 02b_voice_pillars...   → 10角色说话风格 + 交叉叙事 + 参数表
5. 03_event_system.md     → 全局事件池 + 因果链 + 季节事件
6. 03b_high_pressure...   → 高压事件 + 灰色事件 + JSON数据结构
7. 04_dialogue_scenes.md  → 8个基础场景对话
8. 04b_high_pressure...   → 5个高压场景对话 + 观测者互动
```

### 4.2 核心数据结构

**角色数据**（从02b参数表加载）：
```json
{
  "character_id": 1,
  "name": "马库斯·陈",
  "attributes": {"stamina": "B", "social": "B", "education": "B", "wealth": "B", "career": "B"},
  "starting_cash": 3000,
  "student_loan": 0,
  "monthly_income_base": 2200,
  "monthly_expense_base": 1870,
  "cutline_vulnerability": "economic",
  "voice_profile": "marcus_chen"
}
```

**事件数据**（从03b JSON结构加载）：
```json
{
  "event_id": "E-H01",
  "trigger": {"primary_condition": "economic_cutline >= dangerous", "probability": 0.25},
  "choices": [{"choice_id": "A", "text": "...", "outcomes": {...}}],
  "character_voice_variations": {"marcus_chen": "...", "zoe_wilson": "..."}
}
```

**对话数据**（从04系列加载）：
```
场景ID → 角色 → 分支节点 → 选项 → 后果标记
格式：类Ink/Yarn——分支标注清晰，可直接转换
```

### 4.4 关键设计约束

1. **事件触发不打断玩家操作流**——事件以弹窗/浮层形式呈现，玩家可以在短时间内做出选择
2. **角色Voice Pillars用于动态文本生成**——同一事件的不同角色看到的叙事文本不同（从`character_voice_variations`字段读取）
3. **斩杀线感知信号（01）用于UI状态更新**——不是显示数字，而是显示对应的环境信号文本
4. **情感曲线（01）用于调控事件触发概率**——在"喘息"月份降低负面事件概率，在"高潮"月份提高
5. **多周目变化（01）通过"前世记忆"标记实现**——第二周目同一角色时，部分事件出现额外选项

### 4.5 常见问题

**Q：事件触发概率如何与情感曲线配合？**
A：在`trigger.probability`基础上，乘以当月的情感曲线系数。例如：1月（喘息月）负面事件概率×0.7；7月（高潮月）负面事件概率×1.3。

**Q：角色专属事件和全局事件冲突怎么办？**
A：优先级：角色专属 > 高压 > 季节 > 全局。同一周期只触发1个事件，按优先级选择。

**Q：Voice Pillars如何影响对话？**
A：对话系统中每个NPC台词是固定的，但角色的内心独白和选项描述文本从Voice Pillars中动态选择风格。例如：马库斯看到催债信时，独白是短句+叹气；佐伊看到时，独白是精确分析+自我质疑。
