# 《斩杀线》世界观设定 v3.1

> 游戏类型：叙事驱动生存策略游戏
> 背景：当代西方社会（铁岸市）
> 核心概念：每个社会角色都有一条无形的"斩杀线"——跌破即被社会淘汰

---

## 一、核心概念：斩杀线

### 1.1 一句话定义

**斩杀线**是每个人头顶悬浮的无形临界线。它不是某个邪恶组织设计的——它是现代社会自然运转的副产品。银行、信用局、医疗系统、社交网络、职场——每一个系统都有一条隐形的门槛。一旦你跌过这条线，系统不再把你视为"值得投资的人"。

### 1.2 斩杀线的四重维度

```
┌──────────────────────────────────────────────────────────┐
│                    🔴 四重斩杀线                           │
│                                                          │
│  ① 经济斩杀线                                            │
│     临界点：净资产 < $0 且连续 3 个月无改善                 │
│     表现：贷款利率翻倍、消费受限、催收开始                   │
│     叙事：你不再被信任。系统收回了它的"善意"。               │
│                                                          │
│  ② 体力斩杀线                                            │
│     临界点：健康状况严重恶化（慢性病/过劳/心理崩溃）         │
│     表现：无法工作、收入归零、医疗费用飙升                   │
│     叙事：身体不关心你的计划。它有自己的底线。               │
│                                                          │
│  ③ 社交斩杀线                                            │
│     临界点：社会关系网络断裂 + 信用评级降至最低档            │
│     表现：无法获得推荐/担保、婚姻危机、被社交圈排斥           │
│     叙事：当你最需要帮助时，没有人接电话。                  │
│                                                          │
│  ④ 存在斩杀线                                            │
│     临界点：失去合法身份/医疗保障/住房                      │
│     表现：从系统记录中消失、无法证明"你是谁"                │
│     叙事：你不是死了。你是不存在了。                        │
│                                                          │
│  ⚠ 四线全触发 → 「斩杀」                                  │
│     游戏结束。但这不是戏剧性的死亡——                       │
│     是逐渐的、安静的、从社会结构中的消失。                   │
└──────────────────────────────────────────────────────────┘
```

### 1.3 斩杀线的玩家感知信号表（关键优化）

玩家不会看到"斩杀线数值"。他们通过以下信号感知危险：

| 斩杀线距离 | 经济信号 | 体力信号 | 社交信号 | 存在信号 |
|:--------:|----------|----------|----------|----------|
| **安全** | 银行App正常打开；信用卡可用；收银台不紧张 | 睡醒有精神；不需要咖啡也能工作 | 手机有未读消息；有人约周末 | 驾照在钱包里；医保卡有效；信箱里有你的名字 |
| **警戒** | 刷卡时犹豫；开始看账户余额；取消了一个订阅 | 早上需要两个闹钟；午饭后犯困 | 消息回复变慢；有人的聚会没叫你 | 收到"身份验证"邮件；某个自动扣款失败 |
| **危险** | 收到第一封催款信（白色）；开始用信用卡付房租 | 失眠；腰背持续疼痛；咖啡从1杯变3杯 | 朋友说"改天"但没定日期；前任开始减少联系 | 医保被暂停（"处理中"）；驾照即将过期 |
| **临界** | 催款信变成黄色；有人打电话来催；开始考虑当铺 | 爬楼梯喘气；生病不敢请假；止痛药在增加 | 没有人主动联系；在街上假装没看到熟人 | 收到"请更新您的信息"通知；某些表格需要额外证明 |
| **即将触发** | 红色催款信；门上贴了通知；工资卡被冻结 | 身体某个部位持续疼痛；医生说"需要进一步检查" | 电话簿里的人都变成了"已读不回"；婚姻在崩溃边缘 | 信件开始用"居民"代替名字；系统提示"信息不匹配" |
| **触发** | 账户被冻结；资产被清算；驱逐执行 | 无法起床；住院；收入完全中断 | 被社交圈彻底排斥；离婚协议在桌上 | 信件退回"查无此人"；无法通过任何身份验证 |

### 1.4 斩杀线的叙事隐喻

- **斩杀线不是反派设计的**——是银行的风控算法、保险公司的精算表、HR的绩效考核、社交圈的隐性筛选共同编织的网
- **没有人绝对安全**——离斩杀线的距离取决于你的起点，但意外可以在一瞬间将任何人推到边缘
- **斩杀线是渐进的**——它不是悬崖，是斜坡。你不会"突然跌落"——你会先收到警告信，然后是第二封，然后是红色的那封
- **最恐怖的不是死亡**——是"被系统判定为不值得存在"。你的名字从记录中消失，你的故事不再被讲述

## 二、世界观：铁岸市

### 2.1 城市概述

**铁岸市 (Ironbank)** 是一座典型的美国中西部后工业城市。它曾经繁荣——汽车工厂、钢铁厂、铁路枢纽。现在工厂大多关了。剩下的被自动化取代了。

人口：约280,000（从巅峰期的450,000下降）
气候：寒冷冬季，炎热夏季——中西部标准配置

### 2.2 城市空间与具体地点

城市被**M-7号高速公路**一分为二。

| 区域 | 特征 | 居民 | 关键地点 |
|------|------|------|----------|
| **北岸** | 金融区、科技园区、高档住宅、私立学校 | "活着的人"——信用评分700+ | 铁岸第一银行总部、ClearScore大厦、北岸购物中心、圣约瑟私立医院 |
| **南岸** | 废弃工厂、廉价公寓、当铺和发薪日贷款店 | "挣扎的人"——信用评分不可查 | 南温斯顿街1147号（互助会）、老铁厂遗址、南岸社区诊所（排队3小时） |
| **中环** | 物流中心、连锁商店、普通住宅区 | "悬在中间的人"——离斩杀线只有一张工资单的距离 | M-7物流中心、中环信用合作社、圣约瑟公立医院（急诊室永远满员） |

### 2.3 玩家会频繁接触的具体地点

| 地点 | 区域 | 叙事功能 | 氛围 |
|------|------|----------|------|
| **铁岸第一银行大厅** | 北岸 | 贷款申请、账户问题、与格洛丽亚互动 | 大理石地板 + 磨损地毯区（富人和穷人的不同路径）、永远排队的个人贷款窗口 |
| **M-7物流中心** | 中环 | 底层工作来源、与利奥首次接触 | 混凝土+荧光灯、24小时运转、停车场永远有车在发动 |
| **南温斯顿街1147号** | 南岸 | 互助会据点、灰色经济入口 | 废弃仓库外表+意外整洁的内部、旧咖啡机永远在工作 |
| **圣约瑟公立医院急诊室** | 中环 | 医疗危机、存在斩杀线体验 | 等候区分两种人：有保险的（坐着）和没保险的（站着，在算值不值得等） |
| **中环信用合作社** | 中环 | 替代金融渠道（格洛丽亚推荐） | 小而温暖，不像银行——更像社区中心 |
| **铁岸市住房管理局** | 南岸 | 驱逐、法拍、住房危机 | 灰色建筑、永远在排队、工作人员的眼神是"我见过太多" |
| **北岸购物中心** | 北岸 | 消费决策、社交展示 | 对比——当你在南岸挣扎时，这里的人们在买$7的咖啡 |
| **老铁厂遗址** | 南岸 | 城市历史的伤口 | 废弃的厂房、生锈的"招工"牌子还在——上面写着"已截止，2008" |

### 2.4 核心机构

这些机构不是"反派"——它们只是在执行规则。

| 机构 | 叙事功能 | 玩家会遇到的NPC |
|------|----------|-----------------|
| **铁岸第一银行** | 经济斩杀线执行者 | 格洛丽亚·海耶斯（贷款处理员）、匿名催收部门（只有电话里的声音） |
| **ClearScore信用局** | 社会斩杀线守门人 | 从未出现——只是一个网站和一个三位数的数字 |
| **圣约瑟医疗系统** | 存在斩杀线最后防线 | 分诊护士（问的第一个问题是"你有保险吗"）、疲惫的住院医生 |
| **M-7物流中心** | 底层收入来源 | 排班经理（名字在变化——因为离职率太高）、工友 |
| **南岸互助会** | 灰色经济入口 | 利奥（接头人）、各种"不方便被看到"的人 |
| **铁岸市住房管理局** | 住房斩杀线 | 案件处理员（每人每天处理47个案件）、门口的保安（见过太多崩溃的人） |

### 2.5 时间背景

- **年份**：2024年秋季至2025年冬季
- **经济环境**：温和衰退期——通胀回落但生活成本仍高，就业市场"看起来不错"但新增岗位大多是低薪服务业
- **社会氛围**：焦虑——人们知道系统有问题，但不知道该怎么办

### 3.3 高潮节点设计

游戏有三个"不可回避"的高潮节点：

**第一高潮（4月·报税季）**：无论玩家之前的选择如何，报税日是一次强制的财务清算。退税可能让玩家松一口气——补税可能把玩家推向斩杀线。

**第二高潮（7月·斩杀线临界）**：此时玩家的选择后果全面显现。至少一个斩杀线维度逼近临界。这是"最黑暗的时刻"——也是观测者出现、隐藏结局线开启的时刻。

**第三高潮（9月·结局锁定）**：最终路线确定。玩家看到自己的选择将把他们带向哪个结局。最后几步——无法回头。

## 四、五维社会属性系统

### 4.1 五维属性

| 属性 | 定义 | 影响领域 |
|------|------|----------|
| 💪 **体力** | 健康、精力、抗压能力 | 工作能力、应对突发事件的身体基础 |
| 🤝 **社交** | 人脉、信誉、社交技巧 | 获取机会、求助、婚姻关系 |
| 🎓 **学历** | 教育背景、专业技能 | 收入上限、职业选择、培训效率 |
| 💰 **财富** | 现有资产、财务缓冲 | 抗风险能力、投资选项 |
| 💼 **职业** | 当前工作状态、行业前景 | 收入稳定性、晋升机会、裁员风险 |

### 4.2 属性档位叙事化

| 档位 | 标签 | 叙事含义 |
|:----:|------|----------|
| S | 天赋异禀 | 百里挑一。这个维度是你最大的资本。 |

| B | 中上之资 | 比大多数人都好一点。够用，但不够出色。 |

## 五、叙事设计原则

1. **选择不同质**：选择的是价值观和代价，不是程度差异
2. **后果是延迟的**：今日选择可能三个月后才显现——如真实生活
3. **系统不是反派**：压迫来自系统正常运转，NPC只是执行者
4. **信息不对称**：玩家永远在不确定中决策
5. **微小的温暖**：在最黑暗处留一扇窗——不是救赎，是喘息
6. **斩杀线始终可见**：通过环境信号、NPC态度、信件颜色——不是数字

## 六、斩杀线逆转路径（关键新增）

斩杀线不是"触之即死"。每个维度都有逆转路径——困难、有限、需要前置条件。

### 6.1 经济斩杀线逆转路径

| 阶段 | 逆转方式 | 前置条件 | 代价 |
|------|----------|----------|------|
| 警戒→安全 | 增加收入或削减支出 | 有可削减的支出 | 生活质量下降 |
| 危险→警戒 | 债务重组/信用合作社贷款 | 接触过格洛丽亚推荐的信用合作社 | 信用评分-10 |
| 临界→危险 | 南岸互助会紧急借款 | 接触过利奥 | 欠利奥一个人情 |
| 触发→临界 | 破产保护申请 | 净资产≥-$50K | 保留50%资产，信用降级，3个月零借贷 |

**叙事设计**：逆转不是"回到安全"——是"用未来的代价换取现在的时间"。

### 6.2 体力斩杀线逆转路径

| 阶段 | 逆转方式 | 前置条件 | 代价 |
|------|----------|----------|------|
| 警戒→安全 | 减少工作时间+休息 | 有储蓄缓冲 | 收入减少 |
| 危险→警戒 | 社区诊所免费检查 | 有社区连接 | 排队3小时+有限治疗 |
| 临界→危险 | 紧急医疗基金 | 已加入信用合作社 | $500自付额 |
| 触发→临界 | 慈善护理申请 | 医院被标记为"非营利" | 大量表格+不确定结果 |

**叙事设计**：身体的恢复需要时间——而时间是你最缺的资源。

### 6.3 社交斩杀线逆转路径

| 阶段 | 逆转方式 | 前置条件 | 代价 |
|------|----------|----------|------|
| 警戒→安全 | 主动联系一个疏远的朋友 | 有可联系的人 | 可能被拒绝 |
| 危险→警戒 | 参加社区活动 | 玛格丽特或其他社区NPC | -时间 |
| 临界→危险 | 婚姻咨询/关系修复 | 已婚角色 | -$500 + 不确定结果 |
| 触发→临界 | 彻底重建社交圈 | 接触过观测者网络 | 旧关系断裂+新关系不确定 |

**叙事设计**：关系不能"修复"——只能"重建"。重建的代价是时间和脆弱性。

### 6.4 存在斩杀线逆转路径

| 阶段 | 逆转方式 | 前置条件 | 代价 |
|------|----------|----------|------|
| 警戒→安全 | 更新身份文件/续期医保 | 有合法身份 | -$200-$500 |
| 危险→警戒 | 法律援助 | 接触过社区资源 | 等待时间不确定 |
| 临界→危险 | 观测者网络介入 | 触发隐藏结局线 | 欠观测者一个人情 |
| 触发→临界 | 移民律师/庇护申请 | 特定角色（安娜等） | -$5,000 + 不确定结果 |

**叙事设计**：存在斩杀线是最难逆转的——因为一旦你从系统中"消失"，证明你"存在"的责任在你。

### 6.5 逆转设计原则

1. **逆转不是免费**：每次逆转都有代价——钱、时间、人情、信用
2. **逆转需要前置条件**：如果你从未帮助过社区，社区不会在你需要时出现
3. **逆转是暂时的**：逆转给你喘息空间——不是永久安全
4. **逆转有失败可能**：某些逆转路径的结果不确定（如婚姻咨询、法律援助）

## 七、铁岸市历史事件（关键新增）

城市不是静态的。它的历史塑造了现在。

### 7.1 关键历史事件

| 年份 | 事件 | 对当下的影响 |
|------|------|-------------|
| **1972** | 铁岸钢铁厂开业——城市进入繁荣期 | 北岸的基础设施由此建立 |
| **1986** | M-7高速公路建成——城市被物理分割 | 南岸从此被隔离 |
| **1998** | 第一家汽车工厂迁往墨西哥 | 第一批裁员——1,200人 |
| **2008** | 金融危机——铁岸汽车厂关闭 | 4,500人同日失去工作和养老金（观测者的起源） |
| **2012** | ClearScore信用局在铁岸市设立总部 | 社会评分系统正式进入市民生活 |
| **2016** | M-7物流中心开业——取代工厂成为最大雇主 | 从"制造业"到"零工经济"的转型 |
| **2020** | 疫情——南岸社区诊所关闭，圣约瑟医疗系统垄断 | 医疗可及性急剧下降 |
| **2023** | 铁岸第一银行收购最后一家地方信用合作社 | 金融选择的消失 |
| **2024** | 现在——温和衰退期 | 游戏开始的时间点 |

### 7.2 城市历史如何进入叙事

- 老铁厂遗址（观测者会面地点）：墙上2008年的招工通知——"已截止，2008"
- 马库斯的创伤：2008年工厂关闭时签的自愿离职协议
- 卡洛斯的父亲：2008年罢工失败的工厂工人
- 观测者：2008-2012年在ClearScore工作的前工厂工人
- 利奥：2016年物流中心开业后从建筑工人转型为灰色经济中间人

**2008年是铁岸市的"原罪"——几乎所有角色的创伤都可以追溯到那一年。**

## 八、好运的隐性代价机制（关键新增）

正面事件不是纯粹的"奖励"。每次好运都携带隐性的代价——不是立即的，是延迟的。

### 8.1 好运代价表

| 好运事件 | 隐性代价 | 触发延迟 |
|----------|----------|:--------:|
| E-P01 意外之财（$200-$800） | 3个月后，一笔等额的意外支出（"运气守恒"） | 1-3个月 |
| E-P03 技能变现 | 客户推荐更多客户——你开始超负荷工作（体力消耗+20%） | 1个月后 |
| E-P04 信息优势 | 信息可能不完整——基于不完整信息的决策有30%概率出错 | 即时（隐藏） |
| E-P06 意外的贵人 | 贵人的帮助附带期望——"我只是希望你以后……" | 2-4个月后 |
| E-P07 社区的回报 | 接受帮助=你被标记为"需要帮助的人"——社区看你的方式变了 | 即时（社交微妙变化） |

### 8.2 设计意图

好运不是随机的奖励——它是系统的一部分。每次好运都在问玩家一个问题："你准备好接受这份好运的代价了吗？"

有些代价是立即可见的（选择时标注⚠️）。有些代价是隐藏的——在玩家几乎忘记那份好运时才浮现。这创造了叙事张力：**好运来临时，玩家应该高兴还是警惕？**

## 八、多周目叙事差异（关键新增）

### 8.1 不同角色在同一月份的不同叙事重点

同一月份，不同角色的叙事锚点不同。以下是3个代表性月份的多角色对比：

**12月·圣诞节**：

| 角色 | 叙事焦点 | 核心冲突 |
|------|----------|----------|
| 马库斯（#1） | 艾玛的圣诞礼物——$200预算 vs 她想要的东西 | 父爱 vs 财务现实 |
| 佐伊（#2） | 回家面对父母——"工作怎么样了？" | 期望 vs 现实 |
| 特伦斯（#18） | 父亲的"进展汇报"——在家庭圣诞派对上 | 身份 vs 自由 |
| 安娜（#7） | 第一次被邻居邀请参加圣诞晚餐——不知道该带什么 | 融入 vs 暴露 |
| 瑞秋（#8） | 两个孩子的礼物——莉莉想要和同学一样的东西 | 母爱 vs 无力感 |

**4月·报税季**：

| 角色 | 叙事焦点 | 核心冲突 |
|------|----------|----------|
| 伊桑（#9） | 创业亏损能否抵扣——第一次面对"公司税务" | 创业者身份 vs 财务知识 |
| 凯瑟琳（#12） | 兼职收入 vs 学贷利息抵扣——复杂的税务计算 | 知识 vs 现实应用 |
| 卢娜（#14） | 多平台收入——1099表格堆成山，每一份都是不同的平台 | 零工经济的隐性成本 |
| 维多利亚（#17） | 信托基金的税务——第一次意识到财富管理有多复杂 | 继承 vs 管理 |

**7月·斩杀线临界**：

| 角色 | 叙事焦点 | 核心冲突 |
|------|----------|----------|
| 卡洛斯（#6） | 工会谈判破裂——罢工的代价 vs 接受的代价 | 集体 vs 个人 |

### 8.2 多周目变化：第二次玩同一角色

当玩家第二次选择同一角色时，触发"前世记忆"叙事变体：

```
第一周目：角色以"第一次经历"的方式面对事件。
第二周目：角色偶尔出现"既视感"——"我好像经历过这个。"
          但选择仍然开放——玩家可以用不同策略。
          某些"前世记忆"事件触发（如：提前预感到某个危机）。
第三周目+：解锁"精通模式"——起始资源微调，但挑战也增加。
```

### 8.3 不同角色揭示世界的不同侧面

```
马库斯（#1）→ 揭示：底层劳动市场的运作逻辑
```
