## 二、核心叙事框架速览

### 斩杀线四重维度
经济 / 体力 / 社交 / 存在 —— 各有五级感知信号 + 四级逆转路径

### 铁岸市
北岸 / 中环 / 南岸 —— 8个具体地点 + 6个机构 + 1972-2024历史事件线

### 12个月叙事弧线
10月序章 → 4月第一高潮 → 7月第二高潮（最黑暗时刻）→ 9月第三高潮（结局锁定）
配套：情感曲线图 + 多周目差异

### 20角色
起点6人 + 进阶7人 + 高手7人 —— 每角色完整叙事档案 + 10角色Voice Pillars + 参数化数据表

### 159个事件
全局19 + 高压3 + 灰色2 + 季节6 + 角色专属~110 + 交叉9 + 观测者5 + 因果链扩展

### 18个叙事场景
8个基础 + 5个高压 + 5个冲突/失败变体

### 4种结局
逃出生天 / 灰色永生 / 跌落 / 觉醒（隐藏）

## 三、叙事设计原则

1. **选择不同质** — 选择的是价值观和代价
2. **后果延迟** — 今日选择可能三月后显现
3. **系统非反派** — 压迫来自系统正常运转
4. **信息不对称** — 永远在不确定中决策
5. **微小温暖** — 最黑暗处留一扇窗
6. **斩杀线始终可见** — 通过信号，不是数字
7. **好运有代价** — 正面事件携带延迟的隐性代价（v3.2新增）
8. **逆转需前置** — 斩杀线逆转需要之前积累的资源/关系（v3.2新增）
