# 《斩杀线》角色系统 v3.0

> 20个角色 = 20种"人生假设" × 20个不同的社会切面
> 设计原则：每个角色不是在"选择人生"，而是在"应对已经发生的事"

---

## 一、角色设计框架

每个角色由以下模块构成：

```
角色档案
├── 基本信息（年龄/职业/家庭/起点）
├── 核心创伤（塑造世界观的关键事件）
├── 欲望 vs 需求（表层目标 vs 真正需要的东西）
├── 五维属性（体力/社交/学历/财富/职业）
├── 斩杀线临界点（最脆弱的维度及触发条件）
├── 关键关系（家人/朋友/对手）
├── 专属事件池（5-8个该角色才会触发的特殊事件）
└── 角色弧线（从开局到终局的成长轨迹）
```

#### #1 马库斯·陈 —「普通人」

```
"标准开局。真正的普通人——不靠天赋，全靠选择。"

基本信息：
  年龄：42岁
  职业：M-7物流中心配送员（前汽车零部件工厂中层管理）
  家庭：离异，12岁女儿艾玛由前妻主要抚养
  居住：南岸廉价公寓

五维属性：💪B 🤝B 🎓B 💰B 💼B

核心创伤：
  工厂关闭时，他签了一份"自愿离职"协议换取遣散费。
  后来发现那是公司规避养老金的陷阱。
  他失去了15年的养老金积累，而签署的文件让他无法起诉。

欲望 vs 需求：
  欲望：给女儿一个"正常的生活"——稳定的家、大学基金
  需求：接受"正常"已经不存在了，学会在不稳定中找到稳定

斩杀线临界点：
  经济：女儿的抚养费 + 房租 = 月收入的85%
  社交：前妻正在争取完全抚养权，任何负面记录都是法庭证据
  存在：没有医疗保险，一次意外就足以摧毁一切

关键关系：
  - 艾玛（女儿）：12岁，聪明，正在学会不依赖父亲
  - 前妻凯伦：不是坏人，只是现实——她需要为孩子考虑
  - 德韦恩（旧同事）：工厂关闭后也在挣扎，偶尔联系

专属事件池：
  "前妻的律师信"——她申请完全抚养权
  "艾玛的家长会"——去还是不去？去了可能看到前妻的新伴侣
  "德韦恩的提议"——一个不太正规但能赚钱的活儿
  "工厂旧友聚会"——面对那些曾经和你在同一条线上的人
  "艾玛的生日"——你只有$200预算
  "第二份工作"——夜班保安，但你会更少见到艾玛

角色弧线：
  从一个试图"回到过去"的人，转变为学会"在废墟中建造新东西"的人。
```

#### #2 佐伊·威尔逊 —「知识改变命运」

```
"最优等毕业。学贷少，但期望更高。学术界的规则≠现实世界的规则。"

  她是家里第一个大学生。毕业典礼上，教授说她"会改变世界"。
  六个月后，她同时在改三份简历，没有一份回应。
  她开始怀疑——"Summa Cum Laude"在现实世界到底值什么？

欲望 vs 需求：
  欲望：找到一份"配得上她学历"的工作
  需求：认识到学历是门票，不是通行证——她需要重新学习"街头智慧"

斩杀线临界点：
  经济：学贷$10K虽少，但三份零工的收入勉强覆盖房租+还款
  社交：她的中产阶级社交圈不理解她的挣扎——"你可是Summa啊"
  存在：如果她跌出中产——她的学历就成了"overqualified"的诅咒

关键关系：
  - 母亲：为她骄傲，抵押了房子帮她付学费（她还不知道这个）
  - 大学室友杰西：进了投行，每次聚会都让她感到刺痛
  - 常客"教授"：咖啡店的常客，一个退休的经济学教授，偶尔给出奇怪的"人生建议"

专属事件池：
  "校友会邀请"——$150的入场费 + 面对那些"成功"的同学
  "母亲的秘密"——发现父母抵押了房子供她上学
  "教授的提议"——咖啡店常客提供了一个奇怪的机会
  "学贷公司的'善意提醒'"——如果连续三个月未足额还款
  "梦想工作的面试"——但需要搬到另一个城市，所有积蓄押在这一趟
  "杰西的婚礼"——伴娘礼服$400，单身派对在坎昆

角色弧线：
  从一个"按规则玩游戏的优等生"，转变为学会"质疑规则本身"的人。
```

  "命运的玩笑"——巨大的好运紧接着巨大的厄运

角色弧线：
  从一个"等待运气的赌徒"，转变为"创造自己运气的行动者"。

#### #17 维多利亚·斯特林 —「传承者」

```
"她继承了遗产。不只是钱——还有期望。"

基本信息：
  年龄：29岁
  职业：家族基金会管理员
  继承：祖父留下的$300,000信托基金
  学历：公共管理硕士
  债务：无
  家庭：已婚，丈夫是高中教师
  居住：北岸继承的房产

五维属性：💪B 🤝B 🎓B 💰A 💼B

核心创伤：
  祖父白手起家。从零到百万。然后留给她$300K——"做点有意义的事"。
  但"有意义"是什么？她不知道。她在基金会工作了五年，
  感觉自己只是在管理钱——而不是在创造价值。
  她的祖父在坟墓里看着她。她感觉到了。

欲望 vs 需求：
  欲望：用这笔钱做"有意义的事"——证明她配得上这份遗产
  需求：认识到她的价值不取决于她如何花祖父的钱

斩杀线临界点：
  经济：信托基金有条件——如果净资产低于$100K，"断供"
  社交：她周围的人——包括丈夫——都受她的财富影响，无论她愿不愿意
  存在：她是"斯特林家的孙女"——不是维多利亚

关键关系：
  - 丈夫汤姆：高中教师，爱她但不爱她的钱——至少他这么说
  - 母亲：对"有意义的事"有明确的看法——"别把钱浪费在奇怪的项目上"
  - 基金会顾问：一个精明但冷漠的财务顾问——他看的是数字，不是人

专属事件池：
  "汤姆的尴尬"——他不想用她的钱，但他的教师工资无法支撑"她的生活方式"
  "基金会的审计"——有人质疑她的管理
  "母亲的提议"——"为什么不投资房地产？"
  "一个真正的机会"——一个社区项目需要$50K——这是"有意义的事"吗？
  "断供的威胁"——净资产接近$100K，信托基金的条件开始触发

角色弧线：
  从一个"被遗产定义"的人，转变为"定义遗产含义"的人。
```

#### #18 特伦斯·阿姆斯特朗三世 —「信托基金宝宝」

角色弧线：

  "塌房危机"——一个合作方出了问题，粉丝在攻击她

  "危机公关"——$30,000的公关费用——值得吗？

角色弧线：
  从一个"为人设而活"的人，转变为"为真实而活"的人。

#### #20 马库斯·韦斯特 —「自学天才」

```
"没有学历。没有社交网络。每一次失败都让他更聪明。"

基本信息：
  年龄：28岁
  职业：自由软件开发者
  学历：高中毕业（自学编程）
  债务：无（从未借过钱——因为没有信用记录）
  家庭：单身，有一只叫Bug的猫
  居住：南岸微型公寓

五维属性：💪B 🤝D 🎓D 💰C 💼S

  他没有上大学。不是因为笨——是因为高中时家里付不起申请费。
  他在公共图书馆自学了编程。每一本免费的书，每一个开源的教程。
  他花了五年——比任何CS学位都长——但他做到了。
  现在他靠自由职业赚钱。不多，但够。
  只是——他无法申请那些"需要CS学位"的工作。即使他能做得更好。

欲望 vs 需求：
  欲望：获得认可——不是靠学历，是靠能力
  需求：认识到他不需要"被认可"——他需要"被看见"

斩杀线临界点：
  社交：他的社交技能几乎没有——不是不会，是没时间练习
  经济：自由职业=不稳定。但他不知道如何"找工作"——他从未有过面试
  存在：他在纸面上"不存在"——没有学位，没有信用记录，没有专业网络

关键关系：
  - Bug（猫）：一只从街上捡来的流浪猫——他们互相收养了对方
  - 图书馆管理员：一个看着他自学了五年的人——唯一一个知道他故事的人
  - 一个潜在雇主：给他发了面试邀请——但他不知道该穿什么
  - 在线社区的陌生人：他在Stack Overflow上的"朋友"——从未见过面

专属事件池：
  "面试邀请"——他的作品集被一家公司看到了。他们想见他。
  "Bug生病"——猫需要手术。$3,000。他没有这笔钱。
  "一个不可能的项目"——一个客户要求一个他从未做过的东西。他接下了。
  "图书馆的告别"——管理员退休了。他失去了唯一一个"见证者"。
  "意外的认可"——他的一个开源项目被一家大公司使用了
  "学历的墙"——一个梦想的工作——要求"CS学位或同等学历"。他在"同等学历"上打勾。然后等了三个月。

角色弧线：
  从一个"在阴影中自学"的人，转变为"走向光明，被看见"的人。
```
